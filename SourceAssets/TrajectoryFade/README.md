# 투척선 표시 보수 V0.02

2026-11-17 · 작성자 송예찬

`Apply.cs`는 짧은 표시선·투명도 설정을 Unity AssetDatabase로 저장한다. `Validate.cs`는 Play 모드에서 임시 설정 복제본·바닥·벽을 사용해29항목을 검사한 뒤 위치/상태/오브젝트를 복원한다. `Finish.cs`는 편집 모드 복귀·검수용 백그라운드 설정 복원 후 현재 상태를 기록한다.

Unity CLI `script eval_file`로 각 파일을 실행한다. Assets 안으로 옮기지 않는다. 후속 사용자 설정 변경 뒤 Apply.cs를 자동 재실행하지 않는다. 결과는 [검수 기록](../../Docs/Review/2026-11-17_TrajectoryFade/Review.md)을 따른다.

물리 예측은 실제 발사와 같은 고정 간격을 쓰며3초/60m 한도다. 표시선만2.5/4m로 자르고 페이드한다. 현재 미리보기 원은 표시선이 실제 접촉면까지 닿을 때만 나온다. 선 너머 원은 숨긴다. 빈 공간·예측 한도에는 가짜 원을 만들지 않는다.

V0.01 — 사용자 요청 구현·검수 도구 기록. 송예찬.

최신 검수는 `ValidateVisibleContact.cs`다(34/34). `Validate.cs`의29개 검사는 선 너머 원이 있던 이전 단계다. `prepare_visible_validation.py`는 이전 검사에서 최신 조건을 생성하며, 현재 검수·화면·문서는 V0.02를 따른다.
