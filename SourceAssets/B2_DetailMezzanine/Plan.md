# B2 복층 정비 통로와 기계층 마감 V0.02

작성자 송예찬 · 2026-11-10 · 구현/기술 검수 완료, 사용자 외형 검수 대기

사용자가 Player 조작감을 확인했다. 이번 범위는 B2 정적 레벨이며 게임 코드와 Animator는 보존한다.

통로에서도 상하로 이동하고 상부는 앉아서만 지나는 정비 공간으로 만든다. 기존 원형 내경5m와 평면 연결을 유지한다. 중앙 그레이팅 높이2.42m, 폭1.50m, 하부 유효 높이 약2.30m, 상부 약1.30~1.43m. 상부에 1.20m 크라우칭 캡슐이 통과하며 1.80m 기립 캡슐은 천장에 막혀야 한다. 양 끝13단 계단, 하부는 계단 옆으로 우회한다. 기존 천장등은 상부 동선과 간섭하므로 측면의 실제 붉은 보호망 등기구로 교체한다.

T04(9.1m), T06(11.3m)은 계단 두 개를 넣으면 상부 통행 구간이 거의 남지 않아 단층 접속부로 유지한다. 나머지19개 통로는 독립적으로 상하 이동할 수 있는 복층으로 만든다. 공동 및 코어의 기존 출입구를 보존하며 상부가 문 없이 돔 벽에 막히지 않도록 통로 안에서 하강한다.

상부 바닥은 투시되는 실제 그레이팅, 받침보·난간·발끝막이·체결판·볼트와 베벨을 갖춘다. 물리 바닥은 연속 면을 사용하고 계단은 보이는 단과 일치하는 완만한 경사 충돌로 검증한다. 길찾기 안내는 기존 복도 바닥만 유지한다.

B2 조명은 어둡고 붉은 색으로 정리한다. 흰 주조명 렌즈와 광원을 함께 보수하고 붉은 광원마다 식별 가능한 렌즈·보호망·브래킷을 둔다. 빛만 떠 있는 상태와 벽에 묻힌 등기구를 확인한다. 중앙의 약한 반사광 외에 실제 등기구가 없는 직접 광원을 추가하지 않는다. 기존 흰빛 반사 베이크도 갱신한다.

후속 사용자 검수: 조명이 너무 많고 다른 층과 같아 보인다는 의견을 반영한다. 기존 사각 작업등 대신 원형 주물 보호망등과 금속 갓·와이어 서스펜션을 가진 펜던트를 제작한다. 전체 활성 광원341→158개(반사광12개 포함), 통로 실물등69개 중39개를 상부 배관 점검 위치로 이동한다. 공동마다 펜던트3개와 벽등2개를 기준으로 하되 계단 코어에는 층별 안전등을 둔다.

상부의 존재 이유는 공급·회수 배관과 신호선의 정비다.19개 통로의 상부 양옆에 굵은 배관2열·보조 라인2열, 가스켓 플랜지·벽 지지대·차단 밸브·압력계를 둔다. 양 끝에서 기존 측면 서비스 배관 높이로 내려 연결한다. 가운데1.50m 그레이팅은 통행 공간으로 유지한다.

기계 설비에는 필터 공급/회수 헤더, 공조 덕트 접속·플랜지·벨로즈, 전기 설비 배선을 추가한다. 기존 기기의 앞면 조작부와 출입 동선을 막지 않는다. 철색 재질과 불규칙한 사용감을 유지한다.
