# 1F 근접 디테일 보수 V0.02

작성자 송예찬 · 2026-11-13

벽의 도장 금속판 이음·체결부·국소 마모, 승강기 기계 부품, 줄기와 잎이 겹치는 벽 아이비, 내부 프랍의 기능별 부품을 보강한다. 기존 창 면적·지붕 파손·배치·통행·황야는 유지한다. 승강기 가동부의 기존 부모와 피벗을 유지하며 게임 운행 코드는 사용자가 작성한다.

기존 원본 프랍을 공유하는 다른 층에 영향을 주지 않도록 1F 전용 부가 메시를 기존 배치의 자식으로 연결한다. 작은 부품은 거리별 LOD에 포함한다. 아이비는 기존 에셋 GUID를 유지하고 새 잎과 가지를 제작한다. 기존 충돌체는 유지한다.

제작/검수 C#은 SourceAssets의 외부 도구이며 게임 Assets에 추가하지 않는다. 이전 제작기의 전체 실행은 하지 않는다. 최종 수치와 전후 화면은 작업 후 검수 문서에 기록한다.

## 제작 구성

- `props.py`: 프레스 유압 호스/계기/가이드 칼라, 컨베이어 베어링/장력 조절부/모터, 지게차 체인/호스/조작 레버/타이어, 랙의 브래킷/펀칭/상자 손잡이, 팔레트 못/포장 이음, 드럼/릴의 테두리/체결부, 수납장 힌지/잠금장치, 정비대/카트/책상/의자/검사대 부품.
- `landscape.py`: 벽 14구역의 하단 금속 마감·창 위 물끊기·측면 덮개·체결점, 창 개구부를 피하는 아이비 줄기/가지/잎자루/굽은 잎/잎맥. 잎은 양면 렌더링이며 거리별 3단계 메시를 사용한다.
- `lift.py`: 기존 부모별로 승강기 부가 메시 7종을 제작한다. 같은 문 부품을 카·1F 승강장·B1 승강장의 각 문에 연결한다.
- `AEWeathering.hlsl`: 현재 1F 공용 표면의 도장판 접합부 밝은 모서리·볼트 홈·판 단위 미세 색차·좁은 골 굴곡을 보강한다. 기존 벽돌 제거와 국소 녹 기준을 유지한다.

새 모델은 `Assets/Afrer_Seconds/05.Model/Props/1F/FD_*.fbx`와 `Environment/1F/FD_*_WallTrim.fbx`에 반입한다. 아이비는 기존 `Environment/1F/AE_WallIvy.fbx`를 같은 GUID로 갱신한다. 식생 전용 재질은 같은 층 `Materials/AE_M_Ivy*.mat`이다. 다른 층에서 재사용하는 기존 원본 모델은 수정하지 않는다.

## 승강기 연결

| 기존 부모 | 새 부품 | 후속 사용 |
|---|---|---|
| `Car` | `FD_LiftCar` | 패널·버튼·킥 플레이트·바닥 돌기·환기구·슬링/가이드 부품이 카와 함께 이동 |
| `Car/DoorLeft`, `DoorRight` | `FD_LiftDoorLeft`, `Right` | 문 체결부·롤러·고무 모서리가 해당 문을 따라 이동 |
| `FixedShaft/LandingDoor*`, `Landing_B1/LandingDoor*` | 같은 문 부품 | 각 승강장 문을 따라 이동 |
| `FixedShaft/MachineBedMotorBrake` | `FD_LiftHoist` | 기존 모터의 +0.75m 오프셋 유지, 방열핀·플랜지·브레이크·배선 |
| `Sheave` | `FD_LiftSheave` | 허브 체결부와 브레이크 디스크가 도르래와 함께 회전 |
| `FixedShaft` | `FD_LiftGuides` | 레일 이음/브래킷·피트 스프링·전선관은 고정 |
| `Counterweight` | `FD_LiftCounterweight` | 프레임 체결부와 로프 고정부가 평형추와 함께 이동 |

가동부에는 Static 플래그를 설정하지 않는다. 기존 이동 거리·문 피벗·로프 스케일 기준은 [이전 구조 안내](../F1_RoofLiftWilderness/README.md)를 따른다. 버튼은 정적 외형이며 클릭 판정·운행·문 제어는 연결하지 않는다. `MAX. LOAD` 표기는 아트용 표기이며 게임의 무게 제한 로직이 아니다.

`Apply.Run`은 첫 반입용이다. 후속 변경이 있는 현재 씬에 전체 실행하지 않는다. `Apply.Refine`은 이번 검수 중 이미 연결한 부품을 갱신하는 도구이며 향후 사용자 수정 뒤 임의 재실행하지 않는다. 생성 FBX 후보와 작업 전 백업은 `%LOCALAPPDATA%/Temp/AfterSeconds_DetailPass_20261113/`에 있다.
