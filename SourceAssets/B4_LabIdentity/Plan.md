# B4 실험 시설 정체성 보강 V0.02

작성자 송예찬 · 2026-11-09

사용자 피드백: 책상과 모니터가 많아 사무실처럼 보인다. 전문 설비를 늘리고 측정·실험·관측/기록 영역을 확실히 구별한다. 현재 B4 공동별 목적과 구조, B5, 통행 보수는 유지한다. E02의 연구 업무는 계측·시험조건 검증·기록으로 나누고 기록용 책상은 일부만 남긴다.

| 구역 | 보강 방향 |
|---|---|
| C01 중앙 관찰동 | 피험체 정밀 측정 플랫폼과 다중 광학 센서가 중심 |
| C02 진단동 | 생체신호 수집·센서 준비 장비 강화 |
| C03 계측 준비동 | 광학/전자 계측 장비 교정 작업대와 DAQ 랙 |
| C04 분석동 | 신호 분석·측정용 폐쇄 장비가 있는 실험 작업대 |
| W01 투척 시험 | 충격 센서·교환형 표적·방호 구조 |
| W02 궤적 시험 | 광학 게이트·고속 수집 장비의 실험 축 강화 |

| E03 회복 | 생체계측 카트 보강, 임상/회복 용도 유지 |
| S01 특수 실험 | 하중/차폐 실험 프레임과 구동·보호 설비 강조 |
| C05·E01·N01 | 기록 보관·영상 판독·통제 용도 유지; 필요한 계측 수집 랙 보강 |

전용 모델은 원래 가구/주요 장비의 점유 범위를 기준으로 제작한다. 벽을 새로 세워 이동을 막지 않고, 장비의 보호 케이스·국소 투명 가림·독립 계측부로 작업 영역을 읽히게 한다. 실험 구획을 게임 정답 설명 표지로 표현하지 않는다. 재질은 B4의 어두운 무채색 바탕에 밝은 분체도장·브러시드 금속·검정 광학부를 구분한다. 기존 조명의 밝기/색은 유지한다.

제작 후 모델/재질 누락, 통행과 장비 접근, 기존 씬/게임 코드 보존, 실제 Play와 전후 렌더를 확인한다. 기존 원본은 보존하고 Unity 네이티브 API로 적용한다. 런타임 기능은 구현하지 않는다.

추가 사용자 기준: 1인칭에서 접근 가능한 프랍은 근접 디테일을 우선한다. 문서를 가짜 직선으로 표현하지 않고 읽을 수 있는 제목·회차·측정표·그래프·관찰 메모·확인란을 넣는다. E03 전극 준비대는 새 포장/연결 상태 확인/사용품 회수가 구별되게 하고 패드·젤 접촉부·스냅·개별 포트·집게·접힌 포장·양끝 단자가 있는 리드선까지 표현한다. 화면과 기록의 수치는 정적 아트 예시이며 확정 게임 규칙이나 실제 의학 기준이 아니다.
