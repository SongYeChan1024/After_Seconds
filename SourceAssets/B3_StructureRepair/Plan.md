# B3 구조·설비 밀도 보수 계획 V0.02

작성자 송예찬 · 2026-11-09

사용자 지적 T02–T08 외에 C03 출입부 T07–T08의 외피 겹침도 확인했다. 4.2m 폭의 터널을 공동 외곽 가까운 각도로 연결하면서 벽·바닥·리브·문틀이 중첩됐다. 기존 중앙 경로 이동 통과 결과는 이 외형 문제를 검증하지 못했다.

T08은 C03–C04 연결을 유지하면서 남쪽으로 완만하게 우회한다. 출입구 각도를 벌리고 두 공동의 개구부·벽 패널·문틀·출입등, T08 전체 외피·바닥·리브·설비·안내선을 함께 수정한다. 나머지21개 터널과16개 공동의 위치·층고는 유지한다. 전수 검수에서는 복도 간 교차, 연결 대상이 아닌 공동 관통, 출입부 실내 마감 돌출, 바닥 이음과 실제 통행을 구분한다.

Decision 프랍·환경 제작 목록의 B3 항목을 현재150배치와 대조한다. 큰 공동의 벽 둘레에만 있던 장비를 내부 랙 열·저온 저장 열·검수/포장 작업섬·정비 구역으로 보강한다. 랙 내 용기·서랍, 운반/회수 설비와 작업 소품도 포함한다. 기존 상세 모델의 기능과 재질을 재사용하며 단순 큐브 상자로 수량만 채우지 않는다. 통행과 장비 앞 작업 여유를 함께 검증한다.

플레이어 전용 씬·게임 C#·Animator는 사용자 작업 범위이며 수정하지 않는다. Player·Enemy·UI/UX 같은 기능별 씬은 구버전 정리 대상에서 제외한다. 2026-11-09 사용자 허용 후 Player 작업을 저장하고 B3를 보수했다. 종료 후 Player 씬에 복귀했다. 이후에도 편집 중인 사용자 씬을 전환할 때 작업 시간을 조율한다.
