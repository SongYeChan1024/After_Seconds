# 직접 투척 입력 보수 V0.01

2026-11-17 · 작성자 송예찬

`Validate.cs`를 Play에서 Unity CLI `script eval_file`로 실행한다. 임시 InputSettings 복제본과 실제 InputSystem 상태 이벤트를 사용하며 메서드를 직접 호출해 성공한 것처럼 검사하지 않는다. 임시 바닥/막힘 오브젝트·투척물·설정·위치를 마지막에 복원한다. `Finish.cs`는 편집 상태에서 백그라운드 설정을 복원하고 콘솔 상태를 기록한다.

`Plan.py`는 최초 기획 반영 기록이므로 재실행하지 않는다. 이후 사용자 문서 변경을 덮어쓸 수 있다. 현재 결과는 [검수 기록](../../Docs/Review/2026-11-17_DirectThrow/Review.md)을 따른다.
