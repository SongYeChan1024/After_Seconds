# 1F 창 비율·재질별 지붕 파손 V0.01

작성자: 송예찬 · 2026-11-13

사용자가 지적한 과도한 창 면적과 지붕 구멍의 부족한 묘사를 보수했다. 연구 근거와 제작 범위는 [Plan.md](Plan.md)에 정리했다. 이전 표면 보수, 승강기·VB 계단·황야는 유지한다.

## 창과 벽

주요실 C01–C04·코어 VA/VB/VL·연결 통로 T01–T07의 벽 모델 14개를 수정했다. 길게 이어지는 격자창을 벽 사이에 간격을 둔 창으로 바꿨다. 생산동은 높은 창, 사무 구역은 낮은 창, 코어·통로는 작은 창을 사용한다. 창틀·깨진 유리·창턱은 남기고, 문 위치와 출입구는 보존했다.

수정한 벽 구간의 면적 2,901.02㎡에 대한 창 개구 면적은 1,299.68㎡(44.8%)에서 574.42㎡(19.8%)로 줄었다. 약 55.8% 감소다. 이 값은 **창틀 안 전체 개구부의 설계 면적**이며, 남아 있는 유리 조각의 실제 표면적이나 화면 픽셀 비율이 아니다. 문 위 헤더·지붕 박공·배경 별채 골조는 이 계산에 포함하지 않았다. 계산 원본은 `windows.json`이다.

## 지붕 파손

금속 지붕 9개(C01/C02·T01–T07)는 실제 골판 단면, 얇은 절단 가장자리, 판재 이음부와 체결점, 아래의 받침대를 가진다. 구멍 주변 일부 판재는 고정된 뿌리를 남기고 들리거나 아래로 처진 곡면이다. 콘크리트처럼 두꺼운 쐐기 조각으로 만들지 않았다.

콘크리트 천장 2개(C03/C04)는 22cm 단면에서 깊이가 다른 박락, 거친 골재, 표면 균열과 노출 철근을 표현했다. 철근은 슬래브의 두 직교 방향을 따라 이어지며 끝 일부가 휘거나 끊긴 상태다. 철근의 가는 마디와 파단면 재질은 근접 검수에 반영했다. 코어의 온전한 천장과 승강탑 접속부는 유지했다.

새 재질 4개는 1F 전용 `AE_M_RoofFracture`, `RoofAggregate`, `RoofRawSteel`, `RoofEdgeRust`다. 기존 1F 재질을 변경하지 않고 단면·골재·노출 금속·절단부 녹에 사용한다. 기존 텍스처를 사용하며 새 이미지 생성은 없다.

## 작업 원본과 재개

- `models.py`: Blender에서 지정 벽 14개·지붕 11개만 제작한다. 공통 메시 함수는 `../F1_RoofLiftWilderness/meshlib.py`다.
- `Apply.cs`: 기존 25 FBX의 GUID를 유지하는 Unity 네이티브 반입. `Concrete`는 콘크리트 2개의 근접 마감, `Metal`은 금속판 9개의 얇은 뒷면/옆면 마감 단계다. 현재 씬에 일괄 재실행하지 않는다.
- `Review.cs`, `Inspect.cs`, `Walk.cs`, `PlayCheck.cs`, `Finish.cs`, `Bake.cs`: 외부 Editor 검수 도구다. 게임 코드나 컴포넌트로 등록하지 않았다.
- `setup.py`: 처음 작업 직전 백업과 검수 파일 준비 이력이다. 후속 수정 뒤 재실행하지 않는다.
- `report.py`: 저장된 근거를 바탕으로 로컬 검수 문서만 생성한다.

대상 모델은 `Assets/Afrer_Seconds/05.Model/Environment/1F/`에 있고, 재질은 그 안 `Materials/`에 있다. 임시 후보와 작업 전 백업은 `%LOCALAPPDATA%/Temp/AfterSeconds_WindowRoofDamage_20261113/`에 있다. 저장된 `Level_1F_Factory`가 최신이며 모든 수동 후속 편집보다 제작기 재실행을 우선하지 않는다.
