# 1F 창 비율·지붕 파손 보수 V0.01

작성자: 송예찬 · 2026-11-13

사용자 요청은 창보다 벽이 많은 공장 외형과, 재질별 파손 원리가 읽히는 지붕이다. 현재 표면 재질·승강기·계단·황야는 유지한다. 기존 문과 동선을 보존하며 벽 모델의 연속 격자창을 간격 있는 작은 창으로 바꾼다. 지붕은 C01/C02·T01–T07의 금속판, C03/C04의 철근콘크리트를 각각 보수한다. 코어 VA/VB/VL 천장은 보존한다.

## 조사와 적용

[미국 에너지부 PNNL의 금속 지붕 자료](https://basc.pnnl.gov/resource-guides/metal-roofs)는 노출 체결형 골판 지붕과 지지대, 강풍에 들린 판재의 실제 사진을 설명한다. [FEMA 풍해 조사](https://www.fema.gov/sites/default/files/2020-07/guidelines-wind-vulnerability.pdf)는 이음부 열림과 체결부 배치에 따른 패널 이탈을 다룬다. 시각적으로 골판의 방향, 지지대, 판재 접합과 체결점, 고정된 쪽에서 시작되는 접힘·말림을 반영한다. 게임의 폐공장이 특정 재해를 겪었다고 확정하는 것은 아니다.

[NPS의 역사적 콘크리트 보존 자료](https://www.nps.gov/orgs/1739/upload/preservation-brief-15-concrete.pdf)는 철근 부식에 따른 균열·피복 탈락과 골재 노출을 설명한다. 이에 따라 두께가 있는 불균일 단면, 얕고 깊은 박락 단계, 골재, 기존 슬래브 속에서 이어 나오는 철근, 주변의 작은 균열을 표현한다. 금속처럼 말리거나 얇은 조각이 매달린 형상은 콘크리트에 사용하지 않는다.

## 순서와 검수

1. 저장된 씬·대상 FBX와 메타를 백업하고 동일 카메라의 수정 전 화면을 기록한다.
2. 외부 Blender 도구로 지정 벽/지붕 모델만 제작한다. 기존 GUID를 유지하여 Unity 네이티브 반입하고 재질·충돌 연결을 확인한다.
3. 창 개구 면적 전후, 금속/콘크리트 근접 화면, 통행·참조·실제 Play를 확인한다. 반사와 가림 데이터를 갱신한다.

현재 씬의 오브젝트 위치와 게임 스크립트는 변경하지 않는다. 새 전체 제작기 실행·커밋/push는 이번 범위가 아니다.

변경 이력: V0.01 (2026-11-13) 사용자 요청과 조사 기반 보수 범위. 송예찬.
