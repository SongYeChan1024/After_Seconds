작성자 송예찬 · 2026-11-08

사용자가 T01 외형을 좋다고 확인하고 C02 본체 제작을 요청했다. 지름14m 돔과 T01/T02/T05 출입구를 유지하며 실험·격리 구역의 보안 감시와 인계가 이루어지는 공간으로 제작한다. 설계도의 다중 모니터·PC·인터폰·기록·UPS·보호구·의자 항목을 기준으로 관제석2곳, 대형 감시 화면, 별도 사건 검토 자리, 녹화/네트워크/UPS, 무전기 충전·교대 장비, 기록/장비 수납을 분리한다. 기존 C02 초기 소품2개는 비활성 보관하고 새 정밀 소품으로 대체한다.

북측 관제 벽/책상, 북동쪽 전산 장비, 남서쪽 인계/무전/장비 보관, 남동쪽 기록 보관을 배치한다. 중앙과 출입구3곳의 통행을 비우며 기존 R1에 T05 방향 분기를 연결한다. 구역 이름은 바닥에만 표기한다. 화면은 실제 기존 씬 캡처와 장비 상태를 조합한 정적 텍스처이며 감시·문·경비 동작 코드는 추가하지 않는다.

패널·리브·발판·배선·통풍·문 접합까지 제작한다. C02 쪽 T02/T05 문을 기존 Clinical Portal로 통일하며, T01은 보존한다. 현재187 Light 설정을 유지하고 기존 C02 광원4곳에 실제 등기구 외형을 대응시킨다. 최종 조명·색감 조정은 전체 B5 제작 후다. 모델은 SC_* 이름으로 용도별 Environment/B5·Props/B5 직하에 넣는다. 기존 공유 재질·메시를 덮어쓰지 않는다.

저장되지 않은 사용자 편집과 디스크 씬을 각각 먼저 백업했다. 현재 작업은 로컬 제작이며 커밋·push 범위는 아니다. 제작·기술 검수를 완료했으며 사용자 외형 확인은 남는다. 아래 최종 기록을 따른다.


## 최종 결과

모델14종·배치16곳·재질23개·텍스처13장, 고유 검수 메시239,928tri. 화면15곳은 정적이다. 실제 감시/로그·문·AI 코드가 없다. 새로운 광원 없이 기존187 Light를 보존했다. 출입/설비 접근1,721표본, 전체 출입 왕복6회와 T05 전체1회 통과. Play 두 구간 새 경고/오류0. 바닥 글자/선 최소 여백55.21cm.

- `build.py`, `textures.py`: 새 모델과 정적 장비 화면 제작. 기존 좌표 도우미의 함수만 재사용한다. 기존 제작 스크립트 본문은 실행하지 않는다. `.blend`는 편집 원본이다.

- `Inspect.cs`, `Prepare.cs`, `baseline.json`: 변경 전 실제 씬·사용자 미저장 편집·기존 파일 해시 기록. 최초 기준을 덮어쓰지 않는다.
