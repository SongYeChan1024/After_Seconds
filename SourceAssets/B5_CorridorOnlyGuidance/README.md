# B5 복도 전용 안내선 V0.01

작성자 송예찬 · 2026-11-08

2026-11-08 안내선 복도 한정 완료: 사용자 요청에 따라 돔·계단/승강기 코어 내부의 이동선·화살표·목적지 문자·범례와 실험동 R1/S1/M1 바닥 이동 표기를 제거했다. 19개 복도의 목적지별 색·방향·문자는 유지하고 선 끝은 돔 외곽에서 복도 쪽 20cm에 정렬했다. 기존 안내 Renderer152개를 보존/비활성화하고 복도 구간 메시120개를 적용했다. 저장 씬 재로드 후 정점89,463개를 검사해 돔 내부/복도 밖 안내 정점0, 이전 안내 재노출0. 기존247 Light·Collider·Transform3,582개·대상 씬 외 기존 Assets5,511개 동일. 장비 작업/적재 안전 표시는 유지. **안내선은 앞으로도 복도에만 두며 이전 돔 내부 안내 유지 기록보다 이 결정을 우선한다.** 사용자 외형 검수와 B5 전체 조명 마감은 남음. 로컬 저장, 커밋·push 미실시. 작성자 송예찬.

`Apply.cs`는 Unity Editor에서 기존 안내 메시를 복도 사각 영역으로 잘라 UV/재질을 보존한 `CG_` 메시를 생성한다. 텍스트는 전체가 복도 안에 들어오는 경우만 유지한다. 원본 파일과 GameObject는 보존하고 이전 Renderer만 비활성화한다. 재실행 방지 가드가 있다. `Verify.cs`는 저장 후 모든 정점의 복도/돔 경계를 검사한다. 새 Collider/MonoBehaviour 없음.

기준 좌표: `plan.json`, 실제 절단 경계: 검수 폴더 `apply.json`. 이전 안내 생성기를 그대로 재적용하지 않는다. `Capture.cs`의 `Run` 후 가려진 두 공간은 `FloorOverview`로 보완한다. 보고서는 `report.py`, 보존 검사는 `preservation.py`.
