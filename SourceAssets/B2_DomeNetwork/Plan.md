# B2 공동 설비 밀도·상부 연결 V0.01

작성자 송예찬 · 2026-11-10

사용자 요청: 빈 공동 내부를 역할에 맞는 설비로 채우고 일부 공동의 메자닌을 터널 상부와 연결한다. 기존 어두운 붉은 산업 조명, 하부 보행과 상부 크라우칭 동선을 유지한다.

- C02 냉각 공동의 기존 3.6m U형 메자닌을 T01에 연결한다. 후면 난간에 출입구를 낸다.
- E01 급수, E02 공조, W02 예비 전력 공동에 높이 3.6m 원형 정비 데크와 내부 계단을 만든다. T11·T12·T14·T15·T16의 선택한 끝을 연결하여 총 6통로·7접속부를 만든다.
- 기존 터널의 높이 2.42m 그레이팅을 접속부까지 연장하고 공동 내부에서 3.6m로 상승시킨다. 연결한 끝의 기존 하부 계단은 대체한다. 반대편의 기존 진입 방식은 유지한다.
- 설비는 중앙 공정 장치, 주변 정비/제어 장치, 위쪽 공급·회수 배관으로 구성한다. 출입구 간 통행과 기존 장비 전면 접근을 검증하며 밀도만을 위해 막다른 길을 만들지 않는다.
- 스틸 그레이팅·철골·플랜지·볼트·밸브·압력계·체결부와 베벨을 표현한다. 광원 수를 늘리지 않고 신설 데크 위에 걸리는 기존 펜던트 높이만 조정한다.

모델 원본과 배치 기준은 이 폴더에 보관한다. Unity Editor API로 씬에 반영하고 실제 CharacterController·Play와 시각 검수를 거친다. 게임 기능/Player/Animator는 이번 변경 범위 밖이다. `Apply.Run`은 최초 적용용이며 이후 씬에서는 실행하지 않는다.
