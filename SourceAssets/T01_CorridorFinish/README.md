# T01 실험동–보안관제동 연결 복도 마감 V0.02

작성자 송예찬 · 2026-11-07

사용자의 ‘다음 구역 제작’ 요청에 따라 기존 구역 순서의 T01을 제작한다. C02 돔 본체와 B5 전체 안내선 일괄 적용은 후속 범위다. T01은 길이13.46m·폭4.2m·터널 천장3.4m이며 기존 양방향 문 통행 폭2.4m를 유지한다.

제작 내용은 곡면/하부 벽 모듈 패널, 카트용 보호 레일, 미끄럼 방지 바닥·가장자리 배수/마감, 기존 빈 트레이의 케이블, 도어 전원 점검 장치1곳·환기구2곳·정적 보안 카메라 외형1곳이다. 기존 조명과 주 배관을 연결 기준으로 사용하고 Light 설정은 보존한다. 보안관제동 쪽 구형 출입문은 실험동에서 검수한 Clinical Portal 형태로 맞춘다. 게임 로직은 추가하지 않는다.

구역명은 B5 전체 안내체계 배치안의 T01 표기4곳(C01 실험동·C02 보안관제동)을 바닥에 넣는다. 별도 명판을 추가하지 않는다. 기존 R1 선은 T01 구간 안에서만 중앙으로 정렬하고 바깥 구간은 유지해 선 중복과 새 글자의 겹침을 방지한다. 기존 씬과 모든 에셋을 prepare.py로 먼저 보존한다. Unity 에셋/씬 수정은 실행 중 Editor API로 수행한다.

제작·검수 완료: 모델5종144,164tri, 새 재질10개·텍스처11장·바닥 표기4개. 통행477표본/왕복2회 통과, 실제 Play 내부483프레임·문 통과457프레임에서 새 경고/오류0. 최종 메시 퇴화0·재질 누락0·기존187 Light 변경0. 사용자 외형 검수는 남는다. 문턱 주변±0.8m의 안내선 높이는 표면에 맞추며 바깥 평면 노선은 보존했다. B5 전체 제작 이후 조명·색감을 일괄 조정한다.


## 다시 확인할 파일

- `textures.py`: PBR9장과 한글 목적지 스텐실2장.
- `build.py`: 기존 좌표/베벨 도우미의 함수만 불러와 새 TC 모델5종 생성. 구형 제작 본문은 실행하지 않는다. 케이블 내보내기는 결합 후 기준점을 원점으로 확정한다.
- `Apply.cs`: 저장된 B5 편집 씬에서 자기 그룹/자산·T01 리브 재질·C02 문·R1 참조만 편집. 실행 전 현재 사용자 변경 확인이 필요하다. 이전 문은 비활성 보관한다.
- `Audit.cs`, `GuideScope.cs`, `Walk.cs`: 메시·통행·기존 배치/Light·외부 노선 보존 확인.
- `Play.cs`: 기존 키보드 W 입력으로 복도 내부/새 문 통과 측정. Play 종료 후 `Restore.cs`로 저장 편집 씬 복원.
- `Capture.cs`: 최종6시점, `PlayCapture.cs`: 실제 Game 화면.
- [최종 검수](../../Docs/검수/2026-11-07_T01_Corridor/검수결과.md).

씬 그룹 `B5_Circular_Core_V0.03/T01_Corridor_Finish`. 새 파일은 Environment/B5 직하 TC_* 및 Materials/Textures에 있으며 Blender 원본은 이 폴더에 둔다. 전체 안내선 적용 도구가 기존 CF_R1 대신 TC_R1 참조를 덮어쓸 경우 T01 문턱 높이와 표기 간격을 다시 확인해야 한다.
