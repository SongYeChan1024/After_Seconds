# B2 기계층 전체 연결 제작 V0.01

작성: 송예찬 · 2026-11-09

사용자는 C02 이후 나머지 공동을 이어 붙이고 터널이 큰 배관처럼 느껴지도록 요청했다. 최신 Decision의 12개 공동·3개 코어·21개 연결을 모두 같은 B2 씬에 확장한다. C02 내부 설비·메자닌은 보존하고 출입부만 실제 통로에 맞춘다.

연결 통로는 내부 반지름 2.5m, 중심 높이 1.35m, 최고 높이 3.85m의 원통 단면을 사용한다. 평탄한 바닥에서 폭 약 4.2m가 확보된다. 볼트가 있는 원형 플랜지와 보강 링, 분할 곡면 강판, 측면 공정 배관, 케이블 지지대, 바닥 배수구로 배관 같은 인상을 만든다. 출입구는 원통과 돔의 실제 교차 형태에 맞춰 잘라 막힘·겹침을 방지한다.

터널 외벽 간 충돌과 공동 입구의 좁은 각도를 평면에서 먼저 확인하고 필요한 연결 중심선만 우회한다. 공동의 중심·반지름·역할과 연결 관계를 유지한다. 변경 중심선은 제작 JSON 및 도면 복사본에 남긴다.

원심분리·배전·전력/예비발전·급수·공조/필터·폐수·정비/감시의 역할을 전용 설비와 배치로 구분한다. 기존 VARCO 모델을 우선 재사용하고 신규 비상 발전기는 지정 VARCO flow에서 생성/리메시 후 검사한다. 연결 부품과 치수가 중요한 설비는 Blender로 보강한다. 예각 베벨과 PBR 사용감을 유지한다.

게임 C#·Animator는 추가/변경하지 않는다. 문의 열린 외형과 키패드·계기·CCTV는 정적 아트다. 계단 코어는 상층 경계까지 만들되 미제작 B1 씬 연결을 완성한 것으로 표시하지 않는다.

검수는 터널 전체 폭/머리 여유/바닥, 연결 그래프, 주요 설비 접근, CharacterController, 실제 Play와 OnLook, 누락 에셋·퇴화 면, C02 및 사용자 작업 보존으로 진행한다. 실제 Mouse/Keyboard 비활성화 금지. 커밋·push는 이번 요청 범위에 포함되지 않는다.
