# 1F 표면 디테일 V0.01

작성자: 송예찬 · 2026-11-13

외벽에 드러나던 벽돌 무늬와 금속 전체로 번지던 큰 녹 얼룩을 보수했다. 구조는 앞선 [천장·승강기·계단·황야 작업](../F1_RoofLiftWilderness/README.md)을 유지한다. 이번에는 1F 전용 셰이더와 재질 14개를 수정했다. 게임 코드와 배치를 수정하지 않았다.

## 표면 표현

`AE_M_Plaster`의 기존 에셋 이름/GUID는 참조 보존을 위해 유지했다. 실제 표면은 도장 금속 외장판이며 벽돌 알베도·노멀 연결은 없다. 긴 판재 이음새, 작은 체결점, 국소적인 녹과 가는 빗물 자국으로 구성했다.

금속의 큰 갈색 마스크를 작은 도장 벗겨짐, 노출 금속, 미세한 부식점과 긁힘으로 바꿨다. 박리 가장자리의 미세한 높이와 거칠기 차이를 법선/반사에 반영했다. 외벽·기둥·철판 지붕·설비·승강칸·도르래·난간에 같은 단위의 디테일이 적용되며 색과 마모량은 재질별로 다르다.

콘크리트는 과도하게 굵은 균열을 줄이고 가는 틈과 입자로, 목재는 섬유 방향과 마모로, 고무/직물은 미세한 표면과 낮은 금속성으로 구별했다. 오래된 분위기는 파손 형상·색감·조명·먼지·식생으로 유지한다. 기존 이미지를 다시 그리지 않고 원래 코드 기반의 표면 셰이더를 고쳤다.

## 수정 가능한 값

| 값 | 용도 |
|---|---|
| `_AE_Mode` | 1 금속 외장판, 2 금속, 3 콘크리트, 4 목재, 5 고무, 6 직물 |
| `_AE_WearAmount` | 작은 벗겨짐/부식점의 양. 현재 금속 재질별 0.23–0.48 |
| `_AE_MacroScale` | 마모의 크기 조절. 값이 클수록 작고 촘촘한 마모 |
| `_AE_Seed` | 재질별 무늬 차이 |
| `_BaseColor`, `_Metallic`, `_Smoothness` | 기본색, 금속성, 매끄러움 |

표면 좌표는 오브젝트의 실제 미터 단위와 연결했다. 이후 승강칸/문이 움직일 때 녹이 월드 위치에 붙어 미끄러지지 않도록 했다. 멀리서는 픽셀보다 작은 디테일을 줄여 반짝이는 잡음을 억제한다. URP의 Forward/GBuffer, 조명·그림자 경로와 SRP 배처 상수 버퍼 구조는 유지한다.

## 원본과 검수

- `AEWeathering.hlsl`: 새 표면 표현 원본. Unity의 같은 이름 파일에 반영했다.
- `Apply.cs`: 재질 연결·셰이더 프로퍼티 추가와 검증. 현재 결과에 일괄 재실행하지 않는다.
- `Review.cs`: 같은 시점의 전후 화면과 별도 근접 시야.
- `PlayCheck.cs`: 실제 Play 프레임 진행 중 임시 카메라로 세 지점을 검수. 플레이어/입력은 변경하지 않는다.
- `Finish.cs`: 해당 반사 8개 갱신과 1,778 Transform·165 Collider/참조 보존 검사.

Unity 경로: `Assets/Afrer_Seconds/05.Model/Environment/1F/AEWeathering.hlsl`, `AEWeatheredInput.hlsl`, `AEWeatheredLit.shader`, `Materials/AE_M_*.mat` 중 지정 14개. 1F 밖에서 해당 재질/셰이더를 참조하는 경로는 발견되지 않았다. `report.py`는 저장된 검수 데이터로 아래 로컬 보고서만 생성한다.
