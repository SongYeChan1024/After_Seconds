사용자가 세부 판단을 위임한 제작안이다. 최종 외형 판정은 사용자 검수 후 한다.

| 공간 | 역할과 제작 기준 |
| --- | --- |
| S01 폐쇄시험동 | 교환 현상의 위치·자세 변화를 계측하는 시험실. 흰 임시 표적을 분절형 계측 더미·고정 발판·광학 추적기로 교체한다. 관찰실에서 상태를 기록하며 화면은 정적이다. |
| E03 제염동 | 오염 구역에서 돌아오는 작업자의 보호구 회수·밀봉, 세정·장화 세척, 건조·청결 보호구 재착용. 두 탈의 구역의 용도와 장비를 구분하고 중앙 통행을 유지한다. |
| E02 급식지원동 | 직원용 외부 공급 밀봉 식품의 저온/상온 보관·재가열·검수·카트 출고. 현장 조리나 식당이 아니다. 별도 잠금 인계 장비에는 피험체용 정량 영양팩·투약 소모품을 보관하며 실제 처치/용량 표기는 넣지 않는다. |
| E01 물자보급동 | 중앙 피킹 선반과 외곽 중량 적재 선반을 함께 사용하는 창고. 분류된 상자·용기·정비 케이스, 팔레트·하역 도구, 입고 검사/스캔 작업대를 갖춘다. 출입구와 운반 통로는 비운다. |
| VL 화물승강기 | 보강 문짝·하역 문턱·충돌 방지대·층 표시·호출 조작부·적재 표식으로 화물 설비임을 드러낸다. 정적 외형이며 개폐·층간 이동 기능은 추가하지 않는다. |
| 전기/제어 장치 | 표시등의 베젤·패킹·곡면 렌즈·기능 인쇄·개별 발광, 실제 잡을 수 있는 스위치·분리된 조작부를 보강한다. |

기존 에셋을 덮어쓰지 않는 OD_ 모델 변형으로 제작한다. 원본은 이 폴더, FBX는 용도별 B5 모델 폴더, 출처는 AssetSources에 둔다. C01·기존 광원·게임 코드 보존. 전체 조명/색감은 추후 일괄 검수한다.
