# B4 조명·재질·최적화 및 바닥 사용감 보강 V0.01

작성자 송예찬 · 2026-11-09

사용자가 승인한 순서는 E02/E03에서 조명·재질 기준을 잡고 B4 전체에 적용·검수한 뒤 B3 시료층 제작이다. 추가 요청으로 B5/B4 바닥 패턴과 화물 승강기 사용감의 가시성을 높인다.

- 바닥은 기존 면과 통행 높이를 유지하고 이음선·닦임·불규칙한 사용 흔적을 강화한다. 화물 공간은 바퀴 자국·하단 충격·문턱 마모가 서 있는 시야에서도 보이게 한다.
- B4는 실험대/측정기 중심 작업광과 어두운 통로의 대비를 조정한다. 전체 화면을 밝히거나 색을 과장하지 않고 표면 재질이 읽히도록 한다.
- 가까운 기존 모델은 유지하고, 멀리 보이는 반복 리브/등기구/장비에 별도 LOD를 만든다. 충돌·게임 기능·Player 설정은 보존한다.
- 현재 305개 광원 모두가 Soft Shadow다. 용도·범위·중복을 조사한 뒤 중요한 작업광과 구조 그림자는 유지하고 중복 보조광의 그림자 비용을 줄인다.
- B5 수정은 요청한 바닥/화물 표면에 한정한다. B4 전체 마감 후 최신 Decision 좌표/도면·프랍 목록을 기준으로 B3 시료층의 어두운 창고 분위기와 준비/보관/회수 구역을 제작한다. 게임 내부 스크립트와 조명 스위치 동작은 사용자 직접 구현 범위다.

근접 화면·동일 위치 Play 전후 성능·통행·메시/재질·보호 파일을 확인하고 결과와 남은 범위를 기록한다.
