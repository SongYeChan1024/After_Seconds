# B4 중앙 관찰동 제작 V0.03

2026-11-08 영문 이름 전환: 현재 씬은 SourceAssets/EnglishNaming/name_map.json 기준이다. 이전 일회성 생성·Apply 도구는 당시 이름을 담은 제작 이력으로, 현재 씬에 그대로 재실행하지 않는다. 최신 Review/Audit 도구는 영문 경로에 맞췄다. 새 제작은 처음부터 영어 이름을 사용한다.

작성자 송예찬 · 2026-11-08

Decision `facility_layout.json`의 B4-C01 반지름12m, Y=-66m와 네 출입 방향을 유지한다. B5 현재 외형은 사용자 1차 수용 상태로 보존한다. 기존 Old B4 씬을 재사용해 덮어쓰지 않고 별도 `Level_B4_Circular.unity`를 만든다.

이번 단위는 중앙 관찰동과 T02 접근 복도다. 2.5m 관찰 데크, 양쪽15단 계단과 난간, 시험 바닥, 관측석·준비/기록 설비를 구분한다. 데크 북측50~130도, 계단 폭1.6m·단높이1/6m·단깊이0.28m는 제작 가안이다. 데크 장비는 원 명세의 용도를 유지하고 계단·의자 통행에 맞춰 조정한다. 나머지 층은 후속 제작이며 문은 정적 외형이다.

아트 원본·제작/검수 C#은 이 폴더, 모델/프리팹은 `05.Model/{Environment,Props}/B4`, 맵은 해당 Materials/Textures, 제작 출처는06.Data/AssetSources에 둔다. 기존 모델·재질·씬·게임 코드·Animator를 수정하지 않는다. 새 오브젝트 이름은 `B4_C01_ObservationBooth_01`처럼 구역·기능·번호를 간결한 영어로 작성한다.

검수는 메시/재질·돔/계단/문 충돌·통행 여유·실제 키보드 Play·화면 확인·보호 파일 해시 비교를 포함한다. 초기 `prepare.py`와 씬 Build를 재실행해 후속 작업을 덮어쓰지 않는다.

최종 반영 순서는 `Build.cs` → `Refine.cs` → `FinishArt.cs` → `OcclusionSettings.Detach`다. 기존 B4 씬이 있으면 Build는 중단한다. 이후 수정은 해당 오브젝트만 대상으로 한다. `Refine`은 상부 관측석을 시험 바닥 방향으로 돌리고 좌석 뒤 통행을 확보한다. `FinishArt`는 벽 하단 밀폐 마감과 카메라 벽고정대를 추가한다. 마지막 단계는 새 씬에서 상속된 B5 가림 데이터 참조만 Unity SerializedObject로 해제하며 기존 B5 데이터 파일은 보존한다. B4 전체 확장 후 가림 베이크를 수행한다.

완료 검증·화면·후속 범위: `Docs/검수/2026-11-08_B4_Observation/검수결과.md`. SourceAssets의 검수 C#은 게임 런타임에 반입하지 않는다. `prepare.py`와 `report.py`의 인수인계 버전 갱신은 최초1회용이며 다시 실행하지 않는다.
