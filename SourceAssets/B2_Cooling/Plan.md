# B2 냉각·펌프 공동 제작 V0.01

작성: 송예찬 · 2026-11-09

최신 Decision V0.05의 C02 공동(반지름 11m, 바닥 -34m)부터 제작한다. 이번 범위는 B2 전체 완성이 아니라 대표 공동의 실내와 4개 연결부 마감이다. 전체 12공동·3코어·21복도 배치는 유지한다.

- 높이 3.6m의 U형 메자닌과 양쪽 20단 계단을 도면 좌표에 맞춘다. 스틸 그레이팅은 실제 구멍을 만들고, 지지보·기둥·베이스 플레이트·연결 볼트·난간·발끝막이를 표현한다.
- 하부 냉각 펌프 2대와 탱크 2대를 기존 VARCO 자산에서 검수해 재사용한다. 배관은 접속 플랜지·밸브·압력계·지지대를 포함하여 Blender에서 치수에 맞게 보완한다.
- 정비 작업대·필터·전기 제어함·도구·벽 부착 소방 설비를 추가하되 중앙 및 계단 접근 동선을 비운다. 상부 정비 지점에는 불투명 작업 발판과 설비 엄폐를 둔다.
- 철색 벽/골조에 불규칙 먼지·마찰 흔적을 적용하고 붉은 보조등과 중성 작업등으로 구분한다. 읽을 수 있는 계기와 공정 표기를 만든다.
- 기존 프리뷰와 다른 층은 보존한다. 새 Level_B2_Circular 씬에서 검수한다. 나머지 방과 연결 복도는 후속 제작이며 문을 임의 삭제하지 않는다.
- 런타임 게임 코드·Animator를 수정하지 않는다. 정적 외형과 충돌만 작업한다. 검수 시 실제 Mouse/Keyboard 장치를 비활성화하지 않고, 종료 시 이동과 OnLook을 확인한다.

검수: 메시/재질 누락, 실제 CharacterController 이동, 양쪽 계단 왕복, 그레이팅 시야, 1인칭 조명·근접 디테일, 입력 장치 복구 상태.
