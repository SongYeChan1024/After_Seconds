## 이번 사용자 결정과 제작 범위

- C01 외곽을 실제 업무가 이어지는 고밀도 실험 공간으로 구성한다. 시료 준비·분석·보관·세척·설비 구역을 연결하고 하부 수납, 작업면, 상부 선반/장, 배관의 높이 차이로 밀도를 만든다. 세 출입구와 중앙 포드의 순환 동선은 보존한다.
- CD-040 응급 캐비닛은 불투명한 내부 후면·측면·선반·수납물과 별도 유리를 갖춘 보수본으로 교체한다.
- 점검함은 C01 한 곳으로 모으고 다른 동일 세트는 통풍구만 유지한다.
- 오래된 외형의 관측 콘솔과 깨진 PPE 스테이션은 밀폐형 임상 설비에 맞는 깨끗한 제작본으로 교체한다.
- S1_ServiceBackboard_Support의 시계·기록판은 연속 작업대의 서비스 패널에 통합한다.
- 사용자가 선호한 S1_VitalMonitor_18의 형태를 보존하면서 원본 메시 결함과 세부 형상을 보수한다.
- LP_BenchAnalyzer는 시료 카트리지·트레이·상태 표시를 갖춘 분석 장비로 구체화한다.

기존 사용자 게임 C#·Animator·다른 씬·이전 리브와 플레이어 시작 위치는 보존한다. 모든 제작 C#은 Assets 밖에서 실행한다. 기존 배치는 보관하거나 백업한 뒤 필요한 부분만 교체한다. 외부 생성·push·게시 없이 로컬 제작·검수한다.

C01 중심 (-15,-82,-10), 돔 반경10m. 외곽 주 작업면 반경8.8m, 하부 깊이0.78m, 작업 높이0.93m를 기준으로 한다. 출입축 약5.36°/104.04°/192.14°의 양옆은 문 포켓·통행을 위해 비운다. 실제 충돌 검사에 따라 끝 모듈과 이동형 카트를 조정한다.
