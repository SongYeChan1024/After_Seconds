# 1F 파손 지붕과 수직 동선 및 황야 작업 계획 V0.01

작성자 송예찬 · 2026-11-13

사용자 요청 범위는 네 가지다. 지붕의 열린 면적을 남기면서 네모난 빈 칸을 불규칙한 파손부로 바꾼다. 승강기는 고정 승강로·레일·승강칸·상부 도르래·와이어·균형추를 분리한다. F1_VB_ArrivalFireDoor_01 뒤에는 계단참과 B1 방향 계단을 연결한다. 공장 정문 밖에는 황야와 먼 지평선을 구성해 자유를 향해 걷는 엔딩의 배경을 준비한다.

## 제작 순서와 경계

1. 저장된1F와 기존 미커밋 천장 보수를 기준으로 전후 화면·참조·배치를 기록한다.
2. C01/C02 금속 지붕에는 찢기고 휜 판재, C03/C04 콘크리트에는 불규칙한 절단면과 드러난 철근을 만든다. 연결 복도 지붕의 단순 직선 개구부도 파손 가장자리로 보완한다. 건물 외곽과 통행 높이를 보존한다.
3. VL에는 고정 사각 승강로와 별도 승강칸을 배치한다. 승강칸·문·균형추·도르래의 피벗과 와이어 연결점을 구분한다. 운행·버튼·문 제어 스크립트는 사용자가 후속 작성한다.
4. VB 바닥을 계단 구간만 개방하고 기존 B1 계단의18m 높이와 상부 도착 위치를 맞춘다. 문·계단참·난간을 실제 보행 가능한 구조로 연결한다.
5. 기존 공장 인접 지형과 이어지는 넓은 황야를 만든다. 정문에서 멀어지는 길과 낮은 능선, 마른 식생·돌, 열린 지평선에 집중한다. 엔딩 동작은 구현하지 않고 시작·중간·전망 기준점만 둔다.
6. 변경 구역의 참조·충돌·보행·실제 Play 화면·가림·반사를 확인하고 저장한다. 다른 층·게임C#·Player·Animator와 이전 VA/VB 천장 보수는 보존한다.

승강기의 구조 참고는 [Otis 기본 구성과 권상 방식 자료 8·10쪽](https://products.otis.com/hubfs/E-book%20Spanish/Modernizaci%C3%B3n%20de%20Ascensores%20-%20Tecnolog%C3%ADa%20que%20marca%20la%20diferencia.pdf?hsLang=es-co)이다. 게임용 구조를 자체 제작하며 실제 제품의 치수·설계 규격으로 사용하지 않는다.
