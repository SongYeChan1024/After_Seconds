# B5 돔 천장 조명·터널 등기구 정렬 V0.03

2026-11-08 영문 이름 전환: 현재 씬은 SourceAssets/EnglishNaming/name_map.json 기준이다. 이전 일회성 생성·Apply 도구는 당시 이름을 담은 제작 이력으로, 현재 씬에 그대로 재실행하지 않는다. 최신 Review/Audit 도구는 영문 경로에 맞췄다. 새 제작은 처음부터 영어 이름을 사용한다.

작성자 송예찬 · 2026-11-08

사용자 요청: 터널 조명은 기둥과 겹치지 않도록 기둥 사이에 배치하고, 각 돔 천장에 등기구와 광원을 달아 더 밝게 만든다. 기존 실험동/작업등 설정과 아트·안내선을 보존한다. 전체 색보정의 최종 확정은 사용자 외형 검수 후다.

일반 돔12개의 곡면 천장에 대칭 배치한 밀폐형 등기구를 사용한다. 기존 `CL_PodCeilingLight.fbx`의 베벨·패킹·확산판·체결부를 재사용하고 전용 재질로 광원을 연결한다. 원본 모델과 공유 재질은 수정하지 않는다. 계단/화물 코어의 기존 조명은 유지한다.

터널13개는 실제 활성 리브 위치를 기준으로 인접 리브의 중앙에 기존 등기구/광원을 함께 옮긴다. 양쪽 끝은 문틀–첫/마지막 리브 사이에 배치해 대칭과 출입구 밝기를 유지한다. 리브/등기구가 없는 나머지6개 복도는 기존 광원에 등기구 외형을 연결한다. 기존 위치를 기준으로 되돌릴 수 있도록 백업과 변경 목록을 남긴다.

현재 씬의 그룹과 등기구 이름은 `C01_CeilingLights`, `C01_CeilingLight_01`처럼 간결한 영어로 통일했다. 이 폴더의 초기 생성 코드는 당시 제작 이력이므로 최신 씬에 그대로 재적용하지 않는다.

검수: 동일 카메라의 전후 화면, 천장/리브 간섭·광원 일치, 저장/재로드 참조, 기존 배치·Collider·비대상 Light·게임 코드 보존. 실제 실행 결과와 최종 수치는 검수 문서에 기록한다.


완료: 돔80등, 복도98등 이동·29등 외형 보강(새13광원), 총340 Light. [검수 결과](../../Docs/검수/2026-11-08_B5_CeilingLighting/검수결과.md)와 [전후 화면](../../Docs/검수/2026-11-08_B5_CeilingLighting/review.html)을 따른다.

`prepare.py`, `plan.py`, `Apply.cs`는 최초 작업용이다. 현재 씬에 다시 적용하지 않는다. `Audit.cs`와 `preservation.py`는 저장 상태 비교용이며 before/baseline은 덮어쓰지 않는다. `Capture.After` 재실행 시 `C04Comparison`도 뒤에 실행한다. `Play.cs`는 Assets 밖에서 실행하는 일시 검수 코드이며 게임 코드가 아니다. 검수 전용 경로 오류/중단 자료는 probe에 구분했다. `run_play.py`는 기본5구역, `--ceilings`는 천장 시야2구역을 확인하고 종료 시 배경 실행을 복구한다.

새 천장등은 URP 저해상도 그림자와 개별 bias(0.01/0.015)를 사용한다. 확산판은 `_EMISSION`과 BakedEmissive 플래그를 함께 저장해 URP 재임포트 후 발광이 유지되도록 했다. 새 라이트의 실제 조명은 Realtime Spot이다.
