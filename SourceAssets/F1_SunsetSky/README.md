# 1F 석양 하늘과 황야 조명 V0.03

최신 태양 확대·광륜·Bloom 보수 원본은 [F1_FirstLight](../F1_FirstLight/README.md)다. 아래 내용과 이 폴더의 셰이더는 최초 석양 제작 당시 기록이며 최신 에셋에 덮어쓰지 않는다.

작성자 송예찬 · 2026-11-13

사용자 요청에 따라 HDRI 파일 없이 편집 가능한 석양 스카이박스를 제작한다. 서쪽 출구와 황야 진행 방향에 낮은 태양을 두고 주황색 수평선에서 보랏빛 상공으로 이어지는 색, 얇은 구름, 같은 방향의 햇빛과 거리 안개를 맞춘다. 1F 전용 셰이더·재질을 추가하고 기존 하늘 에셋은 보관한다.

기존 구조·기물·충돌체·승강기 가동부·게임 코드는 유지한다. SourceAssets의 C#은 외부 제작·검수용이며 런타임에 넣지 않는다. 스카이박스는 실측 HDRI가 아닌 정적인 절차적 아트다. 이전 전체 제작기와 이번 첫 Apply를 현재 씬에 재실행하지 않는다.

변경 기록: V0.01 — 제작 범위·표현 방향·보존 기준. 송예찬.


최종 재질은 `Assets/Afrer_Seconds/05.Model/Environment/1F/Materials/FS_SunsetSky.mat`, 셰이더는 같은 층의 `FS_SunsetSky.shader`다. 원래 `FW_WildernessSky.mat`는 보관했다. 태양 위치는 고도5°·Y회전88°이며 재질의 `_SunDirection`을 기존 주광 방향과 맞췄다. 정적 하늘이므로 향후 태양 회전을 바꿀 때 이 방향도 함께 맞춘다. 재질의 색·노출·구름 양·태양 크기는 직접 조절할 수 있다.

[검수](../../Docs/Review/2026-11-13_1F_SunsetSky/Review.md)와 [전후 화면](../../Docs/Review/2026-11-13_1F_SunsetSky/review.html)을 따른다. 첫 Apply·Before 캡처는 후속 변경과 백업을 덮어쓸 수 있으므로 재실행하지 않는다.

변경 기록: V0.02 — 최종 에셋·조절 항목·정적 태양 방향·검수 경로. 송예찬.

변경 기록: V0.03 — 후속 태양/Bloom 제작 원본 연결. 송예찬.
