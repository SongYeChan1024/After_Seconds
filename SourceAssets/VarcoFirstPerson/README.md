# VARCO 1인칭 동작 반입·보정 V0.01

2026-11-17 · 작성자 송예찬

사용자 요청으로 VARCO 카탈로그를 검색하고 기존 After Seconds 리그에 `throw_baseball`을 적용했다. 새 결과는 `source.json`에 기록한 Animate 노드에서 받았으며 0포인트로 처리됐다. 기존 사용자 선택 걷기·달리기는 교체하지 않고 같은 클립에서 양손 경로를 추출했다.

## 반입과 연결

1. `Original/throw_baseball.fbx`: VARCO 원본 다운로드. 기존 수리 리깅 모델과 별도로 보관한다.
2. `prepare.py`: Blender 5.2에서 원본의 뼈/애니메이션만 FBX로 내보낸다. 새 FBX에는 메시가 없다. 원본 수리 모델을 다시 덮어쓰지 않는다.
3. `ImportAndScan.cs`: Unity Humanoid 반입 및 기존 V0.3 Avatar에 재생해 손 경로를 조사한다. 전체 클립은 30fps, 약3.333초다.
4. `BakeAndConnect.cs`: 기존 걷기·달리기와 새 투척 클립을 샘플링하고 `PlayerHandAnimations.asset`에 손 경로를 저장한다. 프리팹의 `animations`, `bodyAnimator` 참조만 연결한다.
5. `ValidatePlay.cs`, `CaptureFinal.cs`, `Audit.cs`: 실제 플레이 검사·촬영·참조 확인. 편집 상태와 입력 설정을 복원한다.

현재 저장된 에셋이 결과물이다. 사용자 후속 편집 뒤 반입기/베이크를 일괄 실행하면 클립 설정이나 곡선을 덮어쓸 수 있으므로 필요한 단계만 사용한다.

## 1인칭 보정

- 걷기1.2초·달리기약1.567초의 손목−어깨 상대 경로를 각각61/81표본으로 추출한다. 루프 끝의 차이를 제거하고 화면용 진폭으로 재생한다.
- 하체 Animator의 normalizedTime과 손 곡선의 위상을 공유한다. 실제 이동 속도에 따라 진폭을 줄이며 정지·조준·확대·점프/착지 반응은 기존 처리를 유지한다.
- 새 투척 원본의2.0→2.133333초를 준비 동작으로,2.133333→2.55초를 방출 후 팔 동작으로 쓴다. 준비0.18초, 후속 동작0.42초다.
- 원본 전신 투척을 카메라 팔에 그대로 적용하지 않는다. 손 경로를 제한하고 IK로 팔을 연결해 화면 구도를 유지한다. 전신 Animator Controller는 그대로다.
- 버튼 해제 시 물체를 먼저 지연시키지 않는다. 실제 방출 콜백에서 표시 물체를 숨긴 같은 프레임에 후속 동작을 시작한다.
- 전용 underhand/toss 키는 확인되지 않았다. 아래 던지기는 기존0.24초 절차적 동작을 유지한다. 점프·착지는 이번에 새 클립을 연결한 항목이 아니다.

사용자 후속 요청으로 아래 던지기 설정은6m/s·상승35도·손(0.26,-0.34,0.68)m로 보완했다. 위 던지기는12m/s·8도다. 확대 시 아래 손은8cm 추가로 올리며, 아래 방출 후 팔 상승도 보완했다. `TuneUnderhand.cs`가 해당 시험값을 적용하고 `ValidateModes.cs`가 R 전환·시야·속도·실제 충돌을 검사한다.

## 도구 사용 시 주의

Unity CLI의 `script eval_file`로 `.cs`를 실행하며 이 파일들을 Assets 아래로 옮기지 않는다. 검수 스크립트는 임시 InputSettings 복제본·장치 활성화·Game View 포커스로 자동 입력을 전달한 후 원래 설정을 복원한다. 첫 검사에서는 포커스 때문에 키 입력이 전달되지 않았으며 `input_harness_attempt.txt`에 남겼다. 장치 활성화 보완 후 실제 속도와 프레임 진행을 확인했다.
