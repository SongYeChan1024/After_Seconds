# 실험동 출입구 타일 연결 V0.01

작성자: 송예찬 · 2026-11-07

사용자가 지적한 회색 비대칭 부분은 문 본체가 아니라 아치 위의 타일 누락이었다. 기존 곡면 마감은 출입축17도 이내에서4.01m 아래의 타일을 통째로 생략해 문마다 회색 노출 폭이 달랐다.

`build_tiles.py`는 그 생략된 영역만 기존 곡률·두께24mm·가로/세로 조인트에 맞게 채운다. 실제 아치 단면을 Boolean으로 제외하고 가장자리3mm 베벨을 적용했다. 최종20조각을1개 메시/14,337tri로 합쳤다. 기존 벽 모델·문·리브는 수정하지 않는다. `Apply.cs`로 `AF_C01_PortalTileInfill`을 실험동에 추가하고 기존 `S1_Coat` 재질을 참조한다.

`Inspect.cs` / `Apply.cs` / `Capture.cs`는 외부 Editor 제작·검수 도구다. 게임 코드는 없다. `prepare.py`는 씬과 재질 원문을 Temp에 백업한다. 사용자 조명 편집이 도중에 확인되어 `PreservePending.cs`로 현재 상태를 별도 백업·저장한 뒤 적용했다. `finish.py`의 씬 비교는 이어진 조명 작업 직전 백업을 타일 작업의 종료 상태로 사용한다.
