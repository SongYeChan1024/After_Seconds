# 1F 코어 천장 틈 보수 원본 V0.01

작성자 송예찬 · 2026-11-13

계단 A·B와 화물 승강기 구역의 온전한 지붕에 남은 2cm 패널 간격을 닫았다. 최신 [검수 결과](../../Docs/Review/2026-11-13_1F_CoreRoof/Review.md)와 [전후 화면](../../Docs/Review/2026-11-13_1F_CoreRoof/review.html)을 따른다.

- `repair.py`: Blender5.2에서 기존 치수와 축·UV 투영·재질명·오브젝트명을 사용해 세 지붕만 제작한다. Unity 바깥의 출력 경로를 필수 인자로 받으며 전체 제작기를 실행하지 않는다. 각 모델은 연속 슬래브1개·기존 가장자리 턱2개,36삼각형이다.
- `Inspect.cs`: 현재1F 참조 검사와 임시 카메라 캡처. 저장된 편집 씬에서만 실행한다.
- `CoreRoofCheck.cs`: 보수 전후 Transform, GUID/fileID·bounds·재질, 천장 틈162표본을 기록한다. 임시 MeshCollider는 즉시 제거한다.
- `Apply.cs`: 임시 후보 폴더의3FBX만 기존 파일에 반입한다. 원본과 .meta를 임시 백업하며 중복 적용을 거부한다. **이미 적용했으므로 재실행하지 않는다.**
- `Reflections.cs`: 기존 코어 반사3개만 같은 EXR 경로에 갱신한다. 임시 플레이어/반사 모드 변경 후 원래 저장된 씬을 다시 연다. 이미 갱신했으므로 재실행하지 않는다.
- `Finish.cs`: 저장 상태와 입력을 기록하고 Scene 뷰를 계단 A 천장으로 맞춘다.

C# 검수 도구의 작업 디렉터리는 해당 PC의 임시 폴더 아래 `AfterSeconds_1F_Review_20261113`이다. 실제 근거 JSON과 전후 이미지는 위 검수 폴더에 보관했다. 원본3FBX는 Git에서 이번 보수 이전 버전으로도 확인할 수 있다.

기존 `F1_AbandonedCamouflage/architecture.py`는 이전 제작 이력이다. 재실행하면 현재의 틈 보수가 사라진다. 후속 편집은 현재 FBX·씬을 먼저 확인하고 지정된 범위에만 적용한다.
