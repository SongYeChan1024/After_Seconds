# 1F 폐공장 전체 제작 원본 V0.03

**이 문서는 초기 운영형 1F의 이력이다. 사용자가 위장 폐공장으로 정정해 전체 환경과 표면을 후속 보수했다. 현재 작업은 SourceAssets/F1_AbandonedCamouflage와 Docs/Review/2026-11-12_1F_Abandoned를 따른다. 이 단계 제작기를 재실행하지 않는다.**

이전 단계 기록:

작성자 송예찬 · 2026-11-12

사용자가 B1 검수 뒤 마지막 지상 1층 전체 제작을 요청했다. 새1F 씬을 저장했고84/84통행·실제Play8곳·Look·깊이 충돌·모델 품질 검수를 통과했다. 전체 아트 최종 수용은 사용자 검수 뒤 결정한다.

- 기준: 현행 메인 기획 V0.81, Decision `facility_layout.json`의 1F 4구역·3코어·외부 출구와7연결, 1F 실내 조감도.
- 좌표: VA(-44,28), VB(44,-28), VL(44,28), C01(-12,0), C02(24,-8), C03(-30,-26), C04(-12,25), OUT(-51,-28). Unity X/Z, 지상 바닥 Y=0.
- 조감도처럼 직선 벽·철골 트러스·높은 창을 가진 폐공장으로 제작한다. 중심 좌표와 연결 관계를 유지하며 원형 반경은 공간 점유 크기의 기준으로 사용한다.
- 생산동: 낡은 프레스/컨베이어·자재 선반·우회 가능한 작업 통로. 하역장: 화물 인수·팔레트·운반차·지하 승강기 위장 출입. 사무동: 기록/전화/교대·소규모 휴게. 검문 구역: 직원 출입·물품 검사·감시 업무. 출구: 실제 외광·차단기·울타리·외부 마당.
- 계단/승강기 도착 자리는 B1의 실제 마커와 대조한다. 지상에서 다시 올라가는 계단을 만들지 않는다. 닫힌 하행 방화문/승강기 후면으로 올라온 자리를 표현한다.
- 기존 B1 디테일 보수를 보존하고 책상과 소품을 적절히 재사용한다. 신규 산업 프랍은 베벨·조작부·구조/기능별 형상과 LOD를 갖는다. 통행·시선·기물 배치를 먼저 확보한다.
- 새 씬 `Level_1F_Factory.unity`에만 제작한다. 기존 씬·공유 에셋·Player·Animator·게임 C#·빌드 설정은 보존한다. 실제 층간 전환/문·CCTV·승강기·AI·결말은 사용자 게임 구현 범위다.
- 제작 후 native Unity 저장·전체 연결/접근 CharacterController 검수·실제 Play/Look·근접 외형·누락 참조·깊이 충돌·LOD·반사/가림을 확인한다.

과거 B1/다른 층 제작기를 현재 씬에 재실행하지 않는다. 이 폴더도 적용 완료 뒤 후속 사용자 편집에 일괄 재실행하지 않는다. 이번 커밋·push는 요청되지 않았다.


## 적용 결과와 재현 자료

74새FBX·85기물·LOD82·조명37/그림자5·반사7·가림 베이크. 기존Unity13171파일 해시 보존. [검수](../../Docs/Review/2026-11-12_1F_FullFloor/Review.md)와 [화면](../../Docs/Review/2026-11-12_1F_FullFloor/review.html)을 따른다.

`plan.py`→`plan.json`은 원도면 연결을 실제 직선 건물로 해석한 초기 계획이다. `resolve.py`→`resolved.json`이 최종 배치/재사용 모델과 접근 위치의 기준이다. `common.py`·`props.py`·`architecture.py`·`textures.py`는 제작 원본, `floor_fix.py`·`detail_geometry.py`·`wayfinding.py`는 적용한 구조/표지 후속 단계다. `clean.py`는 native Unity 원본 채널을 보존하며 정밀 계획의 중복 면만 잘라 FBX에 다시 저장했다. 마지막 노멀/미세 퇴화면 보수도 반영했다. 현재FBX가 저장된 최종 산출물이며 원시 생성기를 덮어 실행하면 후속 면 정리가 사라진다.

`Apply.cs`는 새 씬 생성 전용이다. 이후 `Polish/Detail/Wayfinding/Finish`를 이미 적용했다. 일부 후속 도구는 반복 실행 시 조명 값을 다시 바꾸므로 재실행하지 않는다. `Review/Walk/Quality/GeometryExport/Play/Look`가 외부 검수 도구이며 Assets 안에 게임 C#을 추가하지 않았다. `Inspect.cs`와 `baseline.py`의 원래 기준선은 덮어쓰지 않는다. `protected_before.json`은 작업 전13171파일, `protected.json`은 작업 뒤 대조 결과다.

현재 저장본에서 새 수정이 필요하면 먼저 조사한 뒤 지정 오브젝트만 수정한다. B1·다른 층의 이전 제작기를 실행하지 않는다. 작성자 송예찬.
