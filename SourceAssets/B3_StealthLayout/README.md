# B3 시료층 제작 원본 V0.01

작성자 송예찬 · 2026-11-06

새 `Level_B3_Stealth.unity`의17구역·27일반 문·계단B 하강부·정적 화물 리프트를 제작했다. 원본 `Level_B3_SampleStorage.unity`는 보존했다. [도면](../../Docs/도면/잠입_탐색/B3_시료층_잠입.png), [검수](../../Docs/검수/2026-11-06_LevelContinuation/검수결과.md)를 먼저 읽는다.

`build_b3.py`는 최신 `layout.json`과 `LevelContinuation/build_sections.py`의 베벨·벽/계단·출력 함수를 사용한다. `LC_B3_Architecture.blend`에는 베벨/가중 노멀을 남겼고 FBX는 재질/구역별 합치기와 명시 삼각화를 적용했다. 모델은 `05.Model/Environment/B3/LC_B3_Architecture.fbx`, 재질은 공용 LP 재질을 참조한다. 원본 FBX를 중복 복사하지 않는다.

6개 시료 랙은 도면 장애물 범위 안에 선반과 밀폐 상자를 넣었다. 세척 피트 깊이1.2m, 검수대, 복도 가림벽, 보관실·전처리실·폐기실·환복실과 설비 공간을 만들었다. 공용 프랍18개와 기존 정적 경비3·연구원1·CCTV2를 배치했다. 리프트 캐빈의 측벽·뒷벽·문 수납부를 평면 장애물에도 반영해 예상 경로가 정면 출입구를 통과한다.

씬 생성은 `LevelContinuation/ApplyContinuation.cs`의 B3 메서드로 최초 적용했다. B4 기반 플레이어/카메라를 재사용하되 B4 건축·조명 베이크 참조를 제거했다. B3 전용 정적 반사10개를 사용하며 톤 프로필과 프랍/문은 공용 리소스다. 완료 씬에 제작 도구를 무작정 재실행하지 않는다.

계단B는 B4 구조를-6.4m로 이어 붙였다. 시작점은 `(u46,h0,v23.5)`, 리프트 목표는 `(u43.5,h0,v11)`이다. 리프트 이동·층 전환·문/키패드·AI는 미구현이다. 잠입 성공과 사람의 길 찾기는 별도 플레이 검증 대상이다.
