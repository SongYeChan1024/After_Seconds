## 오늘의 목표

기획서 V0.1에 남은 🔴·🟡 빈칸을 초안으로 채우고, 직접 검토할 수 있는 형태로 만든다. 검토 의견을 반영한 뒤, 가장 크게 흔들린 규칙(손의 힘 타이밍)을 프로토타입으로 비교할 수 있게 한다.

## 작업 내용

### 1. 기획서 빈칸 초안 (V0.03)

- 3·4·6~10번 방 도면과 배치 표, 풀이, 대비 시간에 할 일, 다른 풀이·지름길 점검표를 썼다.
- 새 규칙은 플레이어 규칙을 늘리지 않고 데이터로 넣었다: 우리(바닥이 1.2m 낮은 칸, 교환으로만 나옴), 방 사이 통로(뒤 문이 닫혀야 앞 문이 열림), 문 끼임(밀어 냄), 탄약 보충(통로에서 3발), 손 닿지 않는 총(손에 돌아옴), 방탄 경비(`bulletproof`).
- 6·7·8번 방은 처음 안을 바꿨다. 6번 「던진 것이 지나갈 땐 판 위에」는 판 위에서 총으로 쏘면 바로 풀렸고, 7번 「높이 던져 두고 쏘기」는 공중에서 바뀌면 떨어지기만 했고, 8번 「탄약 0」은 총을 빼앗는 예외 규칙이 따로 필요했다.

### 2. 구글 문서 검토와 댓글 반영 (V0.04~V0.05)

- 기획서를 구글 문서로 올려 댓글 5개를 받았다: 기획 의도, 정면 주먹, 플레이어 규칙과 시야 창, 세계관, 도면.
- 기획 의도(1.1)를 「3초 뒤 상호작용을 어떻게 재미로 만들까」에서 출발한 흐름으로 다시 쓰고, 원칙은 1.5 설계 원칙으로 옮겼다.
- 세계관(1.4)을 보강했다: 「제7 반응연구소」, 피험체 S-03, 실패작으로 분류돼 폐기 대기, 사실은 책임자가 탈출을 관찰하는 현장 실험, 층마다 드러나는 기록, 책임자와 자리가 바뀌는 결말.
- 9장에 시설 공간 이름(구덩이 → 냉각조, 단상 → 관제 데크 등)과 층 배치(B5 격리층 → 1F 검문소)를 넣었다.

### 3. 방 평면도 (Docs/도면)

- 보내 준 건축 평면도 이미지를 기준으로 SVG 10장을 그렸다. 두꺼운 벽, 양개문 열림 호, 방 이름·크기, 치수선, 「⑤ 시료 저장고 평면도」 제목과 층·축척을 넣었다.
- 손으로 그리지 않고 `make_plans.py`가 배치 표의 좌표에서 그린다. 수치가 바뀌면 스크립트만 고쳐 다시 뽑는다.

### 4. 버전 표기 (V0.06)

- 문서와 빌드 제목 뒤에 V0.01부터 붙이고, 고칠 때마다 0.01씩, 완성되면 V1.0. 파일 이름은 바꾸지 않는다.
- 지난 변경 기록 5건에 V0.01~V0.05를 소급해 붙였다. 문서와 빌드는 따로 센다.

### 5. 웹 프로토타입 빌드 V0.01

- 기존 탈출 방 프로토타입(아티팩트)에 「규칙 모델」 전환을 넣었다. A안은 손의 힘 지연 3초, B안은 0초.
- B안용 시야 창을 새로 만들었다. 맞힌 순간부터 교환까지 대상의 시점을 오른쪽 아래에 그린다. 1인칭이라 내 몸이 없어서 시야 창에서만 보이는 실루엣을 추가했다.
- 화면 위 규칙 문구, 시작 안내, 숨은 데이터 표가 모델에 맞게 바뀐다.

## 발생한 문제

1. 세계관 초안에서 「미래를 보는 실험체인데 왜 주먹은 3초 늦게 닿나, 경비는 왜 바로 반응하나」라는 지적을 받았다.
2. A안으로 가면 경비가 나를 보고 달려올 때 즉시 맞설 수단이 없다.
3. 구글 문서로 올리자 `x −6~6, z 2~13` 같은 칸 18곳에서 물결표가 사라지고 그 사이 글자에 취소선이 그어졌다. 글자 도면도 칸이 어긋났다.
4. 구글 문서 댓글을 지워 달라는 요청이 있었으나 연결 도구로는 댓글을 지울 수 없었다.
5. 평면도에서 통로 이름표가 치수선과, 9번 방 구덩이 이름표가 부스와, 셔터 이름표가 벽과 겹쳤다.
6. 아티팩트 재게시가 거부됐다.

## 원인

1. 원래 기획은 「행동이 3초 늦게 닿는다」(지연)인데, 미리보기 UI를 설명하려고 세계관에 「3초 앞을 본다」(예지)를 덧붙였다. 두 설정이 서로를 설명하지 못한다.
2. A안에서는 주먹·칼·제압의 힘이 3초 뒤에 닿는다. 총은 손을 떠난 물건이라 즉시이므로 문제는 손으로 하는 행동에만 있다.
3. 구글의 마크다운 변환이 `~`가 두 번 나오는 줄을 취소선 문법으로 읽었다. 코드 블록은 고정폭 글꼴 없이 일반 문단으로 들어갔다.
4. 구글 드라이브·문서 연결 도구에 댓글 삭제·답글 기능이 없다.
5. 이름표를 대상 좌표에 그대로 붙였고, 문 옆 통로 표시를 치수선과 같은 높이에 두었다.
6. 이번 세션에서 아티팩트의 현재 버전을 열람하지 않은 상태로 게시했다.

## 해결

1. 두 설정을 A안(지연형)과 B안(예지형)으로 나누어 함께 들고 가기로 했다(기획서 2.1). 총은 두 안에서 같고, 갈리는 건 손의 힘이 언제 닿느냐 하나다.
2. A안 보충책 4가지를 기록했다: 공간에 남는 주먹, 도망을 정식 대응으로(내 속도 4.6 > 경비 3.0m/s), 붙잡힘 1초 유예, 발견 0.5초 여유.
3. Docs API로 취소선을 전부 지우고 물결표 36개를 제자리에 다시 넣었다. 도면 블록 10개는 Courier New 9pt로 바꿨다. 다음 업로드부터는 코드 블록 밖의 `~`를 `\~`로 이스케이프한다(인라인 코드 안은 백슬래시가 남으므로 따로 지움).
4. 댓글을 반영한 기획서로 댓글 없는 새 문서(V0.06)를 만들고, 이전 문서는 지우지 않고 남겼다.
5. 구덩이 이름표에 흰 바탕과 위치 지정을 넣고, 셔터 이름표는 벽 안쪽으로, 통로 표시는 문 오른쪽 아래로 옮겼다.
6. 현재 버전과의 차이를 확인했다(차이는 전부 이번 수정분). 그다음 같은 내용을 다시 게시했다.
