# B5 격리층 레벨 구성 V0.03

2026-11-05 설계 개정: 최신 제작 가안은 [격리층 잠입 평면](도면/잠입_탐색/B5_격리층_잠입.svg)과 메인 기획서V0.15의9.0이다. 초소·모니터링·유틸리티를 실제 실내로 연결하고 직원 통로 우회를 허용한다. 아래는 기존 씬 제작 이력이며 "잠긴 배경 외형"과 "우회 금지"를 새 제작에 적용하지 않는다. 현재 Unity 씬은 새 평면으로 수정하지 않았다. 최신 포드 치수는 메인 기획서9.2의 사용자 유리 포드 기준이다.

## 작업 범위

층별로 별도 씬을 제작한다. 이번 대상은 B5 하나이며 B4 이상의 층은 만들지 않는다.

기준은 [메인 기획서](AfterSeconds_메인기획서.md)의 9장과 9.2·9.3 배치 표다. 전체 건물 이미지의 48×32m 외곽에 방을 맞춰 늘리지 않는다. 기존 `SampleScene`과 플레이어 모델·애니메이션·입력·이동 설정은 보존한다.

대상 씬: `Unity/After_Seconds_Build_V0.01/Assets/Afrer_Seconds/01.Scenes/Level_B5_Isolation.unity`

1. 피험체 격리실: 감방, 경비 A, 가벼운 상자 후보 3개.
2. 연결 통로: 양쪽 문 외형과 두 번 꺾이는 차폐 동선.
3. 냉각조 연결 통로: 남쪽 진입 바닥, 6m 냉각조, 북쪽 바닥과 경비 B·D.
4. B4행 계단 전실과 계단 하부: 다음 층으로 이어질 연결 위치까지만 제작.
5. 경비 초소·모니터링·유틸리티 구역은 잠긴 배경 외형으로 표시한다. 퍼즐 우회로로 열지 않는다.

## 에셋 출처와 한계

Codex CLI에서 `codex mcp login varco-3d` 재인증 후 VARCO MCP의 실제 조회·다운로드를 확인했다. Chrome 직접 제어의 연결 호스트 오류와 구분한다. [After_Second_Env_and_Props_Ver0.01](https://3d.varco.ai/flow/3ace28ca-d501-4921-b5a8-0875b2468245)에는 3D 생성물 22종이 있으며 B5용 환경·소품 8종을 반입했다. 기존 V0.3 보정 플레이어와 AS06 경비도 사용한다. 원본 웹 플레이어를 다시 받아 보정 FBX를 덮어쓰지 않는다.

AS01은 5번 방의 **무거운 궤짝**이므로 B5의 가벼운 상자로 재사용하지 않는다. 가벼운 상자는 별도 기본 메시로 구분한다. 벽·바닥·천장·잠긴 출구 문의 외형은 VARCO 모듈을 사용하고, 감방·철창·통로·문틀과 단순 충돌체는 Unity 기본 메시를 유지한다. 새로운 VARCO 생성·Remesh·PBR 실행은 하지 않았다.

새 환경 재질·모듈은 `Assets/Afrer_Seconds/05.Model/Environment/B5/`에 분류한다. 과거 `03.Art/Candidates/VARCO`는 이동하지 않으며, `04.Prefabs`에는 미완성 외형 후보를 넣지 않는다.

반입 모델은 환경 `05.Model/Environment/VARCO/`와 소품 `05.Model/Props/VARCO/`에 분리한다. 각 폴더의 `source_manifest.json`에 출처·해시·실측·프리팹 위치를 기록한다. 기획 치수의 고정 충돌체와 외형을 분리해 생성 메시의 돌출이 퍼즐 규칙을 바꾸지 않도록 한다.

8종 원본 합계는 4,000,000 triangles·FBX 480,846,944바이트다. 로컬 Blender의 파생본은 합계 84,000 triangles·FBX 10,489,744바이트이며, 색상·노멀 PNG 16개는 최대 2048이다. UV·외부 텍스처 연결과 FBX 재반입은 8/8 통과했고 원본 8개의 SHA-256을 보존했다. 이는 제작용 파생 에셋 수치이며 최종 게임 성능 예산·FPS 검증 결과는 아니다.

씬에는 8종 외형 58개를 배치했다. 냉각조 위에는 바닥이나 다리를 추가하지 않았다. 원본 다운로드와 준비 도구는 로컬 `tmp/B5_Level_20261102/`에 보관한다.

## 기능 범위와 검수

이번 작업은 씬 외형·배치·충돌체·조명이다. 사격·교환·경비 AI·자동문·탄약 보충·체크포인트·실패 복구·층 전환은 별도 구현 대상이다. 시작 감방과 냉각조는 이 기능 없이 정상 경로로 통과할 수 없다. 검수용 위치 이동은 플레이 기능이나 완성된 퍼즐 풀이로 계산하지 않는다.

문은 통행 치수와 향후 가동부 위치를 확인할 열린 외형으로 배치한다. 이후에는 뒤 문이 닫힌 다음 앞 문이 열리는 기획 규칙을 연결한다. 계단 끝 연결문은 B4 씬이 준비될 때까지 막아 둔다.

검수 항목:

- 기존 추적 파일 SHA-256 비교: SampleScene·프리팹·모델·Animator·스크립트·설정 보존.
- 감방에서 냉각조 경비를 직접 볼 수 없는 차폐 구조.
- 철창의 인체 통과 차단과 틈, 감방의 벽·천장 충돌.
- 연결 통로의 폭·연속 바닥·벽 충돌, 냉각조 양옆 우회 차단.
- 기존 플레이어의 접지·카메라·Cinemachine·입력 이벤트·Animator 참조.
- 북쪽 바닥·계단 전실·하부 계단 충돌과 다음 층 연결부.
- 누락 스크립트·메시·재질과 Console 오류, 실제 렌더.

## 검수 결과

Unity 6000.4.0f1에서 편집 검수 **25/25**, Play 이동·충돌 검수 **9/9**를 통과했다. 시작점 접지·철창 및 천장 차단·차폐 통로의 7개 경유점·냉각조 양옆 낙하·북쪽 데크와 계단·잠긴 B4 연결문을 확인했다. 감방 밖과 냉각조 북쪽으로의 임시 이동은 게임 진행 검수와 구분한다.

표지 10개는 정적 메시·PNG 아틀라스로 바꾸고 깊이 검사를 적용해 벽 너머로 비치지 않게 했다. 새 Editor 프로세스에서 참조 유지와 동적 TextMesh가 남지 않은 것을 확인했다. 외형 반입 전후 레벨 충돌체 수는 87개로 동일하다. 기존 추적 파일 285개 중 문서 3개를 제외한 282개의 SHA-256이 동일하며, SampleScene·플레이어·패키지·프로젝트 설정을 보존했다. 임시 Editor 스크립트는 Assets 밖에 보관했고 해당 스크립트를 참조하는 씬·프리팹은 없다.

기록은 [B5 검수 폴더](검수/2026-11-02_B5/)에 보관한다. 원본 생성 모델의 접합면·UV·표면 품질과 실제 성능은 이후 아트 검수 대상으로 남긴다.

**남은 외형 문제:** 내부 렌더의 VARCO 천장에는 검은 삼각형과 갈라진 면이 남아 있다. 기존 기본 천장 Renderer는 꺼져 있어 기본 박스와의 중복 렌더 증거는 없다. 단순화한 메시·기존 노멀맵·정규화 변환을 원본과 비교해야 하며 원인은 아직 확정하지 않았다. 편집·이동 검수 통과를 최종 외형 품질 통과로 해석하지 않는다.
