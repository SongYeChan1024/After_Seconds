## 1. 소지와 선택 규칙

- 별도 인벤토리 창 없이 화면 오른쪽 아래의 소지품 인터페이스에서 마우스 휠로 선택한다.
- 5개를 소지한 상태에서 새 획득을 시도하면 **“공간이 없어”**를 표시하고 막는다. 자동 교체·자동 버리기 없이 소지품과 현장 물건을 그대로 유지한다.
- 한 번에 개별 객체 최대 5개를 소지한다. 손에 선택해 든 물건도 포함한다. 종류 수만 제한하여 같은 종류를 무한히 소지하는 방식은 아니다.
- 모든 객체는 수량 1이며 합쳐지지 않는다. 펜 A와 펜 B, 탄약이 다른 총 A와 총 B는 각각 별도 선택 항목과 소지 공간을 차지한다.
- 총·손전등·기록물도 같은 한도를 적용한다. 묶음 수량 ×N을 표시하지 않고 물건 이름·라벨·고유 표식으로 구분한다. 총에는 그 총의 남은 탄약을 표시한다.
- 모든 경비는 총을 지니며 쓰러뜨리면 얻을 수 있다. 총 획득은 강제하지 않는다. 탄약은 해당 총의 상태이며 총끼리 자동으로 합치지 않는다. 총 자체도 투척 대상으로 제작한다. 소지 탄약 총량은 총별 잔탄 합이며 한 자루 N발의 총만 5개 들면 최대 5N발이다. 🟡 한 자루당 탄약 수를 정한다. 별도 예비 탄약 객체나 탄약 보충 기능은 승인하지 않았다.
- 물건은 다른 층으로 가지고 이동할 수 있다. 층별 표는 주 획득 장소이며 다른 층에서 사용을 금지하는 표가 아니다.
- 위치 교환은 메인 기획서의 확정 규칙을 그대로 따른다. 한 번 던진 물건이 여러 유효 대상에 연속 명중하면 각 명중 시각 +3초에 플레이어와 교환한다. 식판 같은 독립 물체와의 교환은 사용자 확정이다. 전체 목록의 모든 소품이나 고정 설비를 자동으로 허용하는 뜻은 아니다. 경비·쓰러진 경비·휴대품·고정 설비·손에 든 물건의 허용 상태는 [메인 기획서의 유효 대상 표](AfterSeconds_메인기획서.md#유효-대상의-범위)를 따른다. 미정 분류는 임의로 허용하지 않는다.

### 층 이동과 준비의 책임

**사용자 확정.** 세 코어 중 자유롭게 골라 올라가며 아래층으로 돌아갈 수 없다. 무엇을 챙길지는 플레이어가 결정한다. 빈손·탄약 0도 상행할 수 있으나 이후 상황을 해결하지 못해 게임 오버가 생길 수 있다. 자동 보충이나 모든 층의 빈손 통과를 보장하지 않는다. 기록물 전체 수집이나 총 획득을 코어 이용 조건으로 강제하는 것과도 구분한다.

전환할 때 개별 객체 ID·종류·총별 남은 탄약·내용 ID·정의된 도구별 상태·현재 선택을 그대로 유지한다. 같은 종류의 물건을 합치거나 새 객체로 복제하지 않는다. 읽거나 해제한 기록의 진행도 별도로 유지한다. 아래층에 버린 물건·경비 같은 현장 상태는 유지 대상이 아니다. 동시에 발각·경보 정보를 확인해 다음 층 경보 조정에 사용한다. 자세한 구분은 [층간 상태 전달](층간_코어_연결_대조.md)을 따른다.

소지품이 없다는 사실만으로 즉시 게임 오버를 발생시키지는 않는다. 🟡 준비 부족으로 해결 불가능한 상황의 판정·실패 안내·준비를 바꿀 수 있는 재시작 범위는 상세 설계한다. 💡 같은 준비 부족 체크포인트만 반복하지 않고 새 시도를 선택할 수 있게 한다. 실제 하행이나 자동 지급으로 대체하지 않는다.

B5의 첫 식판 사용은 **Cinemachine 컷씬**이다. 받는 척하다 식판을 밀쳐 경비에게 명중시키고, 실제 명중 3초 뒤 교환한다. 조작 복귀 후 식판을 다시 챙길지는 플레이어가 선택한다. 컷씬 소품을 소지 목록에 자동 추가하는 규칙은 없다.

실제 준비 부족 구간은 아직 미배치·미검증이다. [상세 설계](잠입_상호작용_상세설계.md)의 후보마다 우회·대기·제압·다른 코어·현지 획득을 대조한 뒤 도구 필수 여부를 판정한다. 컷씬 후 안전한 수동 학습 기회도 별도로 설계한다. 물건이 유용하다는 이유만으로 필수품 또는 실패 조건으로 지정하지 않는다.

## 3. 읽기와 단말 사용

서류철·클립보드·수첩은 손에 들고 직접 읽는 기록물이다. 보고서를 단순한 줄무늬로 표현하지 않고 제목·개체 번호·날짜·표·관찰 메모가 구분되는 실제 본문을 만든다. 페이지 묶음이나 제본된 기록물 전체가 한 물리 객체이며, 여러 독립 기록물을 소지 중에 합치는 기능은 만들지 않는다.

USB는 직원 업무 자료, 데이터 샤드는 연구소 전용 실험 기록에 사용한다. B5는 개체 관리, B4는 시험 회차, B3는 시료 코드, B2는 설비 번호, B1은 연구 기록, 1F는 운송·출입 기록으로 라벨을 구분한다. USB·샤드의 콘텐츠 식별자는 물리 객체 식별자와 구분하여 같은 모델로 다른 자료를 표현한다.

**기록 갤러리 — 사용자 확정.** 실제 열람한 문서·USB·샤드의 내용을 콘텐츠 ID로 등록해 다시 읽을 수 있게 한다. 자료를 읽은 뒤 원본 물건을 버리거나 상행해도 등록 내용은 유지한다. 갤러리는 기록 열람 화면이고 물리 소지품을 정리하는 인벤토리 창이 아니다. 같은 콘텐츠의 등록과 같은 종류 물건의 비합산 소지 규칙은 구분한다. 획득만 하고 열람하지 않은 USB를 자동 해독하지 않는다.

**열람 중 게임 시간 정지 — 사용자 확정.** 현장 문서·단말·갤러리를 읽는 동안 적·플레이어·물체 비행과 교환/신고/경보/소음 타이머를 함께 멈춘다. 화면을 닫으면 남은 시간에서 이어간다. UI 조작과 자료 재생은 별도로 유지한다.

단말 호환 표식·삽입 방향·회수 연출과 삽입 중 실물의 위치/소지 칸 처리, 갤러리 분류·키·체크포인트/새 회차에서의 해금 보존 범위는 후속 상세 설계다. 읽을 수 없는 단말에서 자료가 사라지거나 복제되지 않도록 한다.

기록은 안내선의 목적지·직원 이동·설비 운용을 유추하는 단서를 제공한다. 기록 매체를 모두 모아야 코어를 사용할 수 있도록 변경하지 않는다. 세 코어 자유 선택과 같은 코어·같은 자리·같은 방향의 층간 씬 전환 결정은 유지한다. 본문과 개별 사건의 세부는 서사 검토 후 확정한다.

## 4. 조명과 기타 도구의 기능 범위

손전등·펜라이트·정비용 손전등은 켜기·끄기 기능을 계획한다. B3는 보관 랙 탐색, B4는 가까운 관찰, B2는 배관·정비 설비 확인에 맞는 외형을 쓴다. 켜진 채 놓거나 던진 뒤에도 빛을 유지하는 방향, 빛이 감지에 미치는 영향, 배터리 소모·파손은 상세 설계 제안이며 확정 수치를 넣지 않는다.

스톱워치·리모컨·호출기·계측기·라벨러·무전기·열쇠 등은 우선 손에 드는 소품으로 설계한다. 목록에 있다는 이유로 타이머·원격 조작·인쇄·무전 수신·새 문 잠금 기능을 자동 추가하지 않는다. 녹음기는 연구원 기록 재생을 계획하되 실제 음성과 재생 기능은 후속 작업이다.

## 6. 제작 순서와 완료 기준

1. 공통 사용 동작을 대표하는 식판·펜·서류철·USB·데이터 샤드·손전등·총을 먼저 준비한다. B5 목록에서 누락되는 숟가락·컵·물병·호출기도 이어서 제작한다.
2. B4 측정 도구, B3 시료 도구, B2 정비 공구, B1 연구 물건, 1F 하역 물건 순서로 확장한다. 층별 구성이 승인됐다는 이유로 모든 모델이 이미 제작됐다고 기록하지 않는다.
3. 기존 독립 자산을 우선 검토한다. 신규 생성은 사용자 지정 VARCO V0.03 흐름에서 후보를 만들고 Blender에서 베벨·형태·UV·재질·밀도를 정리한다. 적합한 생성 결과가 없으면 Blender 직접 제작으로 전환한다.
4. 근접 화면·손 크기·메시 오류·표면 흔적·단순 충돌·참조 보존을 검수한 뒤 에셋 완료로 표시한다. 휠 선택·획득·읽기·단말·사격·투척 기능은 사용자 주도 코드 작업에서 별도로 연결한다.

**기능 검증 항목:** 같은 종류 두 개를 각각 선택할 수 있는지, 손에 든 물건을 포함해 5개가 계산되는지, 여섯 번째 획득으로 한도를 넘지 않는지, 총별 탄약과 문서별 내용이 섞이지 않는지, 층 전환 후 고유 객체·선택·상태가 보존되는지 확인한다. 미발각·추격·신고 상태로 각각 전환해 경보 정보가 유실되지 않는지도 확인한다. 빈손 상행을 허용하고 이후 준비 부족 실패·재도전이 가능한지 검증한다. 5개 소지 중 추가 획득이 “공간이 없어”와 함께 거절되고 물건이 사라지지 않는지, 갤러리 재열람과 열람 중 비행·교환·30초 신고 정지를 확인한다. 빈손 UI·안내의 배치와 표시 시간은 UI/UX 상세 설계에서 정한다.
