## 1 기능과 규칙 분석

기획서에서 확인할 기준:

- 교환 지연은 명중한 순간부터 계산한다. 현재 설정 가안은 3초다.
- 실행 시각이 빠른 예약부터 처리하며, 같은 시각이면 먼저 등록한 예약부터 처리한다.
- 실제 교환에는 처리 순간의 플레이어와 대상의 발 위치를 사용한다.
- 처리 시 대상이 사라졌거나 플레이어의 손에 들려 있으면 해당 교환을 취소한다.
