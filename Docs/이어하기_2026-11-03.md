## 돔 내부 중앙 조명

가운데 등을 돔 안쪽 꼭대기에서 세 가닥 지지선으로 매단 얇은 링 조명으로 교체했다. 외경1.404m이며 실제 조명 하단은 약5.11m다. 생활 공간을 아래로 비추도록 연결했고 기존 돔 밖 Cell_Lamp는 외형·광원만 비활성화했다. 바깥 천장 조명4개와 생활 배치·포드 크기는 유지했다. 상세와 사진은 [돔 내부 조명 검수](검수/2026-11-03_Dome_Interior_Light/돔_내부_조명_검수.md)를 따른다.

## 생활·실험형 격리실 최신 상태

사용자가 조정한 포드 위치 `(0,0,10.32)`와 스케일 `(3,2,3)`을 그대로 저장했다. 외경8.43m·내경7.872m·높이6.442m다. Room01은 폭12m·깊이14m(z2~16), 천장 아래7.2m로 확장했고 돔 꼭대기와 약0.758m 여유가 있다. 기존 전면 통로는 그대로다. 경비는 사용자가 옮긴 `(0,0,5.064)`에서 돔 밖에 있다.

돔 안에는 침구를 얹은 침상, 식탁·고정 스툴·식판·컵·식사, 개인 수납, 세면대·변기·차폐판·폐기함, 검사 모니터를 배치했다. 돔 밖에는 관찰 콘솔·시료 준비대·의료 트롤리를 둔다. 가구는 사람 크기를 유지했다. 내부 바닥 물리 높이0.28m에 맞춰 플레이어 시작Y를0.885m로 조정했고 X/Z와 Controller 설정은 유지했다.

배식구는 두 문짝의 앞뒤 네 면에 같은 금속 인셋·손잡이·힌지 마감이 있고, 실제 개구와 깊이0.42m의 전달함·독립 회전축·문 충돌까지 연결했다. 저장 상태는 닫힘이다. 닫힘18/18차단·열림18/18관통·옆 유리12/12차단, 시작 겹침0·8방향 이동검사를 통과했다. 입력 개폐·잠금·배식·탈출 동작은 미구현이다.

상세와 사진은 [생활형 포드 검수](검수/2026-11-03_Subject_Habitat/생활형_포드_검수.md)를 따른다. 원래 포드 FBX/프리팹과 이번 작업 전 사용자 씬 사본은 보존했다. 아래 작은 포드의 치수·장식 배식구 설명은 이전 작업 기록이며 현재 상태는 이 항목이 우선한다.

## 앞선 에셋 배치 상태

사용자 요청으로 기존 에셋을 B5~1F의 6개 층에 추가 배치했다. B4~1F에는 기존 재제작 건축 모듈의 시각 외형을 적용했다. 건축 프리팹 6종은 `05.Model/Environment/B5`의 원본 한 벌을 상층 5개 씬에서도 참조하며, 이번 작업에서 Common으로 옮기거나 복제하지 않는다.

기존 VARCO V0.01 미반입 에셋 14종을 모두 반입하고 6개 층에 총 29개 시각 인스턴스로 적용했다(지붕 패널 12개 포함). V0.01 22종과 V0.02 26종의 환경·소품 48종을 현행 프리팹 또는 재제작 모듈로 사용한다. 가벼운 상자 15개의 임시 외형도 물류 용기로 연결했다. 상층 5개 씬은 기존 건축 80개 표면에 318개 모듈을 반복 적용했다. B4의 떠 있던 서류장은 바닥으로 내렸다. 저장 씬 재열기·참조·충돌 보존·렌더 검수를 완료했다.

시작 공간은 사용자 추가 요청에 따라 **실제 유리 관찰 포드 모델과 정적 충돌을 제작·반입한 상태**로 바뀌었다. 이전의 참고 이미지만 만든 상태는 종료됐다. 배식구와 탈출 기능은 아직 구현하지 않았다. 상세 경로·충돌 변경·검증 범위는 아래 항목을 따른다.

## 시작 순서

1. 프로젝트 AGENTS.md·CLAUDE.md와 이 문서를 읽는다.
2. Unity는 `Unity/After_Seconds_Build_V0.01`, 버전 6000.4.0f1 / URP 17.4.0을 유지한다.
3. `Assets/Afrer_Seconds/01.Scenes/Stage/Level_B5_Isolation.unity`를 열어 현재 모습부터 본다. 사용자가 천장을 180도 뒤집어 패턴이 보이게 한 상태를 유지한다.
4. 층별 확인은 Stage 아래 B5·B4·B3·B2·B1·1F 씬을 **하나씩** 열어 진행한다. 각 씬에 플레이어·카메라가 있으므로 Player 씬이나 다른 층을 함께 로드하지 않는다.
5. 추가 에셋 배치의 최종 검증 상태와 `Docs/검수/2026-11-03_B5_Clinical_Tone/surface_overlap_audit.json`의 남은 접합부를 확인한다. 일반 벽끼리는 정리했지만 이전 검사에서 전체 표면 후보 26쌍이 남았다.

## 앞선 작업에서 완료한 것

- B5~1F의 6개 층 초안과 환경·프랍 반입 상태를 보존했다. VARCO 추가 설비 6종은 10개, Batch02 20종은 60개 시각 인스턴스로 배치돼 있다.
- 기존 환경·프랍 8종의 손상 감량 메시를 원본에서 복구했다. 건축 벽·관찰창·바닥·천장 6종은 정확한 모듈로 재제작해 B5 54개 인스턴스에 적용했다. 관찰창 유리와 창 뒤 얕은 외형도 분리했다.
- 모델 폴더를 Player/Enemy/Props/Environment로 정리했다. Props·Environment는 층별 및 Common, 그 아래 Materials·Textures만 둔다. 모델·프리팹·메시는 층 폴더에 바로 둔다. VARCO/Batch02/Models/Prefabs 같은 중간 폴더를 다시 만들지 않는다.
- 414개 파일 이동 시 대상 443개 GUID, 6개 씬 참조, 53개 FBX 내부 ID, 40개 프리팹을 검증했다. 출처·반입 기록은 06.Data/AssetSources다. 이동표는 Docs/검수/2026-11-03_ModelFolderCleanup/move_plan.json이다.
- 오래된 미사용 AS05_PlayerDummy의 잘못된 Humanoid 설정만 None으로 수정했다. Hips가 없는 정적 원본이며 역참조 0개였다. 실제 V0.2/V0.3 리그와 Animator는 보존했다. 재반입 후 Console 오류·경고 0건을 확인했다.
- B5 일반 벽 24개에 공용 PBR 머티리얼 1개를 사용한다. BaseColor/Normal/Mask 3장, Mask R=Metallic/G=AO/A=Smoothness, 2m×4m 미터 UV다. 벽별 머티리얼 복제는 하지 않았다. 당시 전체 모델 관련 머티리얼은 94개였으며, 현재 추가 반입 이후의 총수와 구분한다.
- 일반 벽 21개에서 내부/동일 평면 접합을 정리했다. 기존 Collider와 위치/크기는 그대로다. 접합용 렌더 메시의 열린 내부 경계는 이웃 면이 덮는 구조다.
- 감옥 같은 회녹색 띠를 줄이고 흰색·회색·검은 프레임 대비로 바꿨다. 천장/감방/에어록 실시간 조명 18개는 옅은 청백색이다. 경고 색과 설비 고유 색은 유지했다.
- 사용자가 직접 수정한 천장 방향과 현재 벽 위치를 보존해 저장했다. 게임 코드와 Collider를 이번 톤 작업에서 바꾸지 않았다.

## 이전 작은 관찰 포드 기록 — 생활형 격리실로 갱신됨

포드는 B5 `Room01_Isolation` 로컬 `(0,0,10.45)`에 배치했다. 외경 2.81m, 전체 높이 3.221m, 유리 안쪽 지름 2.624m다. 흰색 받침, 얇은 검은 프레임, Alpha 0.12의 유리, 청백색 LED와 닫힌 배식구 외형으로 구성한다. [참고 이미지](Reference/GlassObservationPod_Concept.png)는 제작 방향을 정한 원안으로 보존한다.

파일은 다음 위치에 있다. Unity 경로는 `Assets/Afrer_Seconds/` 기준이다.

- 외형·충돌 모델: `05.Model/Environment/B5/ObservationPod_Visual.fbx`, `ObservationPod_Collision.fbx`.
- 모델 단계 외형 프리팹: `05.Model/Environment/B5/ObservationPod_Visual.prefab`.
- 외형·정적 충돌 조립 프리팹: `04.Prefabs/Environment/ObservationPod.prefab`.
- Blender 원본: 저장소의 `SourceAssets/ObservationPod/ObservationPod.blend`.
- 제작 치수·재질·출처: `06.Data/AssetSources/ObservationPod_source_manifest.json`.

기존 감방의 벽 3개·지붕·철창·벤치 Collider는 삭제하지 않고 비활성화해 보존했다. 포드에는 정적 MeshCollider 24개를 조립했다. 기존 플레이어 시작 위치와 CharacterController 설정은 바꾸지 않았다. 이 변경은 관찰 포드 제작에 한정하며, 다른 층의 퍼즐 Collider를 변경하는 근거로 사용하지 않는다.

Editor 기하 검사에서 시작 위치 겹침 0건, 16방향 벽 Raycast 적중, 8방향 기존 CharacterController.Move의 벽 차단을 확인했다. 결과와 안팎 검수 이미지는 `Docs/검수/2026-11-03_Full_Asset_Placement/`에 있다. 실제 키보드 플레이·탈출 풀이·유리의 사격 및 상호작용 판정 검증과는 구분한다.

배식구는 닫힌 외형이다. 개폐·배식·기어 나가기·포드 탈출·사격·교환은 구현하지 않았다. 메인 기획서 V0.11의 9.2에 포드 제작 상태와 기존 철창 원안을 구분했다. 총 빼앗기·사격·배식구 경로의 세부 설계는 검토 대상으로 남겼다. 플레이어 핵심 규칙과 게임 코드는 이번 모델 제작에서 바꾸지 않았다.

## 바로 이어갈 미완료 작업

- 생활형 포드의 배치·사람 크기·높은 천장·안팎 배식구를 직접 확인한다. 문 입력 개폐와 첫 탈출 방법은 학습 순서에 따라 설계·구현한다.

- 사용자가 `Docs/검수/2026-11-03_Full_Asset_Placement/배치_검수결과.md`와 6개 씬을 보고 에셋 크기·방향·배치 분위기를 확인한다. 셔터·그레이팅 고밀도 모델의 LOD와 목표 기기 성능 검수는 후속 작업이다.
- **깜빡임 잔여 검사:** 이전 검사에 남은 전체 건축 표면 공면 후보 26쌍을 실제 위치에서 확인한다. 에어록 천장 3개, 계단 천장/랜딩, 냉각조 벽 상면/데크, 뒤집은 천장과 벽 상면이 대상이다. 외부 상면의 보이지 않는 접촉도 섞여 있으므로 위치를 보고 판단한다. 천장을 원복하지 않는다.
- 사용자가 6개 층과 관찰 포드를 직접 이동하며 외형·동선·시야를 확인한다. 고정 카메라 렌더와 Editor 기하 검사가 퍼즐 완주를 뜻하지 않는다.
- 포드로 바뀐 시작 공간의 총 빼앗기·사격 경로와 배식구 역할을 기획에서 검토한다. 배식구 탈출이나 유리 통과 규칙을 구현된 기능처럼 기록하지 않는다.
- 미터 UV는 편집 시점에 구운 값이다. 이후 벽 Transform을 바꾸면 UV/접합 메시를 재계산한다. 과거 검수 스크립트 경로를 그대로 실행하면 옛 폴더가 생길 수 있으니 새 경로표를 적용한다.

공용 투척 소품 후보는 상자·시료 용기·물류 용기, 추가 후보는 빈 금속통·손전등·소형 공구 케이스다. 모델 존재와 실제 투척 기능 구현은 구분한다.
