# After Seconds 11월 17일 작업 마감과 이어하기 V0.01

작성자 송예찬 · 2026-11-17

사용자 요청으로 오늘의 플레이어·투척·소지품 연결 작업624파일을 `879c0efae34ab8f263ac298ea35708f523daeb68`로 커밋·push했다. 원격 main과 SHA 일치를 확인했다. 기존 로컬에 남아 있던11월16일 점프·이동·1F 지붕 충돌체 커밋 `cefb0823`도 함께 원격에 반영됐다. 단계별 검수 문서의 ‘이번 커밋/push 없음’은 해당 구현 단계 당시 기록이다.

## 이어서 시작할 때

1. 로컬 변경을 확인한 뒤 `git pull --ff-only`로 원격 main을 받는다. 미보존 변경을 강제 reset/clean하지 않는다.
2. Unity6000.4.0f1로 `Unity/After_Seconds_Build_V0.01`을 연다. 버전을 자동 업그레이드하지 않는다.
3. `Assets/Afrer_Seconds/01.Scenes/Stage/Level_B5_Circular.unity`에서 Play한다. 빈손으로 시작하며 플레이어 앞바닥에 시험용 공1개가 있다.
4. 공을 보고 F로 줍고, 좌클릭 누름/해제로 조준·투척한다. R은 위/아래 전환, Q는 내려놓기, 휠은 개별 소지품 선택이다. 던진 공도 다시 주울 수 있다.
5. [최신 소지품 검수](Review/2026-11-17_PickupLoop/Review.md)와 [도구 안내](../SourceAssets/PickupLoop/README.md)를 먼저 읽는다. 초기 Apply·BuildUI·전체 제작기를 후속 편집 위에 일괄 재실행하지 않는다.

현재 설정 에셋의 위/아래 속도는15/10m/s다. 이전 아래 굴림 검수의4.5m/s와 위12m/s는 당시 시험값이며 자동 복원하지 않는다. 아래 방향은 시선 대비-12도·최종 고도각-75~-5도, 표시선은 일반2.5m·확대4m·불투명도30%다. 선이 표면까지 닿을 때만 접촉 원을 표시한다.

## 커밋 전 확인

- 오늘 커밋624파일: 기존 변경12개와 새612개. 제작 원본·검수 화면·C#·프리팹·설정·한글 폰트·TMP 리소스를 포함한다.
- 새 파일 약90.10MiB, 가장 큰 파일은 VARCO 원본 FBX 약11.72MiB.100MiB 이상 단일 파일 없음.
- 새 Unity `.meta`222개 검사에서 누락·고아·새 GUID 중복0. 변경 대상 JSON 파싱 오류0, 자격 증명 패턴 검출0.
- 직전 소지품 작업에서 보호493파일 중 지정10파일 외483파일과 기존 `.meta`256개가 동일했다. 현재 투척 설정·입력·Animator·프로젝트 설정을 보존했다.
- 프로젝트 전용 폰트는 `Assets/Afrer_Seconds/06.Data/UI/`, TMP 리소스는 `Assets/TextMesh Pro/`다. 기본 리소스 폴더 이동 실패는 취소하고 표준 경로를 유지했다.
- Unity 직렬화 파일의 빈 필드 뒤 공백은 에디터 출력대로 보존했다. 게임 동작 변경 없이 커밋 전 파일 검사를 수행했고 Play 검사를 다시 반복하지 않았다.
