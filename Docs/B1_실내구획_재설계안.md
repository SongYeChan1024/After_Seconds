# B1 실내 구획 재설계안 V0.02

작성자 송예찬 · 2026-11-12

사용자가 11월 11일 합의한 전체 B1 재설계를 승인했다. 기존 13공동·3코어·22통로와 B1 연구 데이터·직원 생활 용도를 유지했다. 아래 구획을 저장된 씬에 반영했고, 세부 배치와 결과는 [현재 검수](Review/2026-11-12_B1_Interior/Review.md)를 따른다. 사용자 전체 외형·공간 검수는 남아 있다.

기존 보수된 가구·메시·재질을 재사용한다. 새 건축은 베벨 처리한 얇은 칸막이, 사람이 지나는 개구부, 지지 구조가 있는 부분 천장으로 구성한다. 기존 돔을 채우는 일괄 낮은 천장을 만들지 않는다. 광원은 기존 구역 광원 일부를 새 천장 아래로 옮겨 활용한다.

저장 전 실제 Collider 기반 통행·작업면 접근, 8인 회의석과 발표 화면, 침실 입구 시야, 새 메시 내부/상호 깊이 충돌, 실제 Play 입력과 프레임 진행, 다른 층·게임 C#·Player·Animator 보존을 확인한다. 보안문·CCTV·AI·승강기 작동·층 전환 및 1F 제작은 이 작업에 포함하지 않는다.

구현 결과는17개 체류 구획·103개 벽 구간·21개 부분 천장·203개 주요 배치다. 통행297/297·공용 우회104/104, 실제 Play13구역과 침실/회의석 시야 검수를 통과했다. 기존 조명44개를 천장 아래로 이동하고 반사·가림 데이터를 갱신했다. 천장 틈을 유지하도록 가림 베이크의 최소 구멍 크기를0.25m에서0.05m로 조정했다.

- V0.02 (2026-11-12): 전체 구획 구현·검수 결과와 최종 배치도 연결. 송예찬.
