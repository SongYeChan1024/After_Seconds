쌍은 경로별로 합산한 수이고 메시 수는 실제 배치별 수다. 같은 이름을 가진 여러 타일·옹벽은 개별 인스턴스로 처리했다. 숨은 외부 접촉도 포함하므로72쌍을 모두 플레이 중 보이는 깜박임으로 세지는 않는다. 앞선71쌍 진단보다 건축 검사 범위를 넓혀 B4의 접촉1쌍을 추가했다.

## 수정 방법과 보존

문틀을 우선 유지하고 벽·바닥·천장의 같은 방향 중복 삼각형을 평면 차집합으로 잘랐다. B4 관측 복도의 북쪽 벽은 연속된 외피를 유지하고 연결 복도 쪽을 자르도록 근접 화면을 확인해 조정했다. 면을 조금 밀어 겹침을 숨기는 방식은 쓰지 않았다.

새 정점의 위치·노멀·UV·UV2·tangent는 원래 삼각형의 값에서 보간했다. 원본 메시와 재질·텍스처는 유지한다. 파생 메시 위치는 `Assets/Afrer_Seconds/05.Model/Environment/{B5,B4,B3}/WF_*_SeamFixed.asset`다. 씬의 MeshFilter 참조만 바꿨으며 원래 프리팹을 일괄 수정하지 않았다. 연결 위치·원본·제거 면적은 [application.json](application.json)에 기록했다.

수정 대상81개 메시의 삼각형 합계는134,628개에서135,247개로 약0.46% 늘었다. 파생 메시 파일 합계는 약12.54MiB다. 절단 경계를 다시 나누면서 삼각형 수가 소폭 증가했으며 실제 FPS 측정은 하지 않았다.

- 사용자 저장 B5 씬을 작업 시작 기준으로 보존했다. B3·B4·B5의 전체 씬 텍스트를 시작 사본과 비교해 시각 메시 참조 이외의 변경이 없음을 확인했다.
- B2·B1·1F 씬은 파일까지 동일하다. 전층 기존 Transform·Collider·Behaviour, 문 개구와 포드·경비 배치는 유지했다.
- 원래 모델·프리팹·meta·이전 소품 베벨/스무스·작업대 색 보정본·Packages·ProjectSettings의 보호 파일1237개는 SHA-256이 동일하다.
- 파생 메시의 인덱스·유한한 좌표/tangent·노멀 및 UV 채널 수를 검사했다. 누락 메시0건, 비어 있는 시각 메시0개다.

저장 후 보호 검사는 [preservation.json](preservation.json), 메시 검사는 [mesh_validation.json](mesh_validation.json), 파일·씬 비교와 최종 수치는 [final_verification.json](final_verification.json)에 있다. 반입 출처는 Unity `06.Data/AssetSources/WallFrameRepair_20261104.json`에 있다.

## 수치 검사의 범위와 한계

활성·불투명 건축 시각 메시를 대상으로 같은 방향의 축 정렬 면을 비교했다. 삼각형 면적0.00005㎡ 이상, 평면 간격0.5mm 이하, 축 방향 편차 및 꼭짓점 평면 편차 조건을 사용했다. 경로 쌍의 합산 겹침0.002㎡ 초과를 보고했고 배치별 제거 면적0.0001㎡ 미만은 수치 오차 수준으로 제외했다. [수정 전](overlaps_before.json)과 [저장 후](remaining_overlaps.json)는 동일한 기준이다.

차집합은 알려진 포함·부분 겹침·비접촉 사례와 무작위150사례에서 면적 보존을 검사했다. 저장된 메시를 다시 내보내 잔여 겹침을 독립적으로 계산했다. 이 검사는 모든 각도의 비축 정렬 면·한 메시 내부의 자기 교차·반투명 유리의 품질 통과를 뜻하지 않는다. 기존 베이크의 선무늬와 덕트 형상 품질도 별도 항목이다.

실제 키보드 이동·문 작동·퍼즐 완주·목표 기기 성능은 아직 검사하지 않았다. 새 Collider·게임 로직·건축 베벨은 추가하지 않았다. 재현 도구는 [tools](tools/)에 보관하고 실행용 임시 Editor 코드는 Assets 밖으로 치웠다. Git 커밋·push는 이번 요청에서 수행하지 않았다.
