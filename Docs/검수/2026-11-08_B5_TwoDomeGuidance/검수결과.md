# B5 두 돔 안내선 정리 검수 V0.01

작성자 송예찬 · 2026-11-08

사용자가 확정한 방식에 따라 **각 돔에서 갈 수 있는 목적지 기준**으로 안내한다. 현재 C01 실험동과 C02 보안관제동 사이에 청록 C01행·파랑 C02행 두 선만 남겼다. T01에서는 두 선을 평행 배치하고 각 목적지까지 연결한다. 계단A 녹색·유틸리티동 보라색 및 그쪽으로 이어지던 경로/바닥 표기는 현장 적용에서 제외했다. 다른 돔을 제작·연결할 때 해당 목적지의 선을 추가한다.

두 색상 안내판도 바닥 인쇄로 갱신했으며 벽 명판을 추가하지 않았다. 기존 실험동 내부 흰 R1 순환선과 S1/M1 국소 작업 표기는 유지한다. 관제 피드4장도 두 선이 보이는 현재 씬으로 갱신했다. 모두 정적 화면이다.
