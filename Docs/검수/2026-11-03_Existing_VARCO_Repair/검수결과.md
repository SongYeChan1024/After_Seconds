# 기존 VARCO 환경·프랍 메시 복구 검수 V0.01

2026-11-03 · 작성자 송예찬

기존 환경·프랍 8종의 고해상도 원본은 각각 500,000 triangles이며 위치 용접 후 열린 경계가 모두 0개였다. 기존 감량 FBX는 9,148~20,282개의 열린 경계가 있었다. 원본의 UV/노멀 분리 버텍스를 용접하기 전에 감량한 과정과 일치하는 손상이다. 불투명 머티리얼 설정만의 문제가 아니다.

원본 버텍스를 먼저 용접하고 감량한 뒤 국소 관통 부위를 재구성했다. 전체 사각형 수동 리토폴로지는 아니다. FBX 재수입에서 작은 분리 잔여 삼각형이 생긴 천장·금속벽은 해당 독립 조각을 제거하고 다시 검증했다. 원본 FBX·텍스처·.meta는 보존하고 Repaired/Models에 FBX 및 기존 로컬 bounds에 맞춘 .asset 메시를 추가했다. 기존 프리팹 GUID/계층/배치/충돌체는 유지했다. 노멀맵 강도는 1에서 0.35로 조정했다.

천장 패널은 8,000 목표에서 관통 625건이 발생하여 목표를 32,000으로 올렸다. 최종 31,218 triangles에서 통과했다. 유료 재생성은 수행하지 않았다.

## 남은 원본 형상 문제

- 관찰창: 원본 자체에 불투명한 막 같은 면이 있다. 투명 유리·창틀을 분리한 재제작/재생성을 권장한다. 이번 토폴로지 복구가 창 너머 시야를 보장하지는 않는다.
- 콘크리트벽·문벽: 볼트 관통 구멍·불규칙한 외곽이 원본에 있어 B5에서 외부 색이 보이는 부분과 모듈 경계 틈이 남는다. 닫힌 메시도 터널 모양 구멍을 가질 수 있다. 정확한 직육면체 건축 모듈에 표면 디테일을 얹는 후속 재구성이 적절하다.
- 금속벽의 가는 돌기·찌그러진 외곽은 원본 실루엣이다. 관통·열린 면은 복구했으나 CAD처럼 반듯해진 것은 아니다.
- 기존 AS01_Crate/AS05_PlayerDummy/AS06_GuardDummy도 추가 검사했다. 각 8,000 triangles, 열린 경계·과다 공유 모서리·퇴화면 0개다. 이 3종의 전면 관통 검사와 캐릭터 리깅 검사는 하지 않았다. 캐릭터·Animator·코드는 변경하지 않았다.

## Unity 확인

B5 환경·프랍 58개 인스턴스가 복구 메시를 참조한다. 추가 Batch02 20종은 6개 씬에 60개 배치했다. 저장 씬을 다시 열어 기존 Collider 스냅샷 동일, 신규 Collider 없음, 신규 에셋 AABB와 기존 충돌체 겹침 0건, 메시·머티리얼 참조 정상, missing script 없음 확인. 렌더 이미지를 시각 검수했으며 직접 이동하는 플레이테스트는 하지 않았다.

교차 검사는 엄격한 edge-triangle 관통 검사이며 모든 공면 중첩·접촉을 완전 검증한 것은 아니다. export_verification.json이 최종 FBX 수치다. 원본 URL/SHA256과 변경 전 프리팹/머티리얼 백업을 함께 보관했다.
