# 1F 코어 천장 틈 보수 검수 V0.01

작성자 송예찬 · 2026-11-13 · Unity 6000.4.0f1

지상 1층을 다시 확인하면서 계단 A·계단 B·화물 승강기 구역의 천장에 하늘이 가는 선으로 비치는 현상을 발견했다. 제작 원본은 이 세 코어를 온전한 지붕으로 구분하지만, 4×4 패널 사이에 2cm 간격을 두고 있었다. 각 코어의 패널을 연속된 콘크리트 판으로 연결하고 기존 가장자리 턱 두 개를 유지했다.

[전후 화면](review.html) · [제작 원본](../../../SourceAssets/F1_CoreRoofRepair/README.md)

## 변경 결과

- `AE_VA_Roof`, `AE_VB_Roof`, `AE_VL_Roof`의 기존 FBX 3개를 보수했다. 각 모델은 216삼각형에서 36삼각형으로 줄었다.
- 외곽 범위·높이·월드 기준 UV 배율·기존 콘크리트 재질 연결을 유지했다. 해당 구역의 128px 반사 이미지 3개를 갱신했다.
- 생산동의 의도된 파손 지붕, 벽·바닥 재질, 외부 지형·식생은 이번에 수정하지 않았다.

틈 검사는 검수 중에만 만든 MeshCollider를 사용했으며 씬에는 추가하지 않았다. 이번에는 외형과 참조 보존을 검수했고, 실제 Play 이동 검사와 전층 성능 측정은 재실행하지 않았다. 기존 가림 데이터는 최소 구멍 크기0.1m이며 이번 0.02m 틈 보수에서는 재베이크하지 않았다.

## 이어서 할 일

현재 `Level_1F_Factory`의 저장된 편집 상태에서 계단 A 천장을 확인할 수 있다. 다음은 사용자 전체1F 분위기·표면·지형 검수와 구체적인 지적 구역 보수다. 이번 천장 보수를 전체 아트의 최종 수용으로 기록하지 않는다.

로컬 저장 상태이며 이번 변경의 커밋·push·블로그 게시를 실행하지 않았다. 이전 `F1_AbandonedCamouflage/architecture.py`를 일괄 실행하면 천장 틈이 다시 생기므로 현재 모델을 덮어쓰지 않는다.
