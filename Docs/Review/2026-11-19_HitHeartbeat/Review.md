# After Seconds B5 피격과 교환 박동 검수 V0.02

2026-11-19 · Unity 6000.4.0f1

[B5 관제 경비 피격부터 교환까지 · 소리 포함 4.27초](B5_HitHeartbeat.mp4)

플레이어가 C01 배식 경비에게서 얻은 권총으로 C02 관제 경비를 맞힌다. 관제 경비는 즉시 쓰러져 총을 떨어뜨린다. 1초와 2초에 박동이 들리면서 가장자리에 흰 안개가 차올랐다 걷히고, 3초째에는 가장 큰 박동과 함께 플레이어와 쓰러진 경비가 자리를 바꾼다. 총은 떨어진 자리에 남는다.

## 양쪽의 피격

| 상황 | 플레이에서 확인한 결과 |
| --- | --- |
| 플레이어가 권총으로 경비를 맞힘 | 첫 명중 때 추격·사격·붙잡기가 멈춘다. 3초 뒤 양쪽의 그때 위치를 교환하고 한 번 떨어뜨린 총은 다시 생성되지 않는다. |
| 플레이어가 경비 뒤에서 F를 누름 | 즉시 제압하고 총을 떨어뜨린다. 가까이서 떨어진 총을 보고 F를 다시 누르면 그 총과 실제 잔탄을 얻는다. |
| 발각 후 경비의 사선 안에 머묾 | 경비가 조준을 1.4초간 예고하고, 사선이 유지되면 자기 권총에서 한 발을 쓴다. 예고 도중 엄폐하면 발사와 잔탄 소모가 취소된다. |
| 플레이어가 맞음 | HP 3에서 한 발에 1씩 줄고 1.25초간 지상 목표 속도가 평소의 60%가 된다. HP가 0이 되거나 경비에게 붙잡히면 Enter로 재시도한다. 새 시도에서 플레이어는 HP 3, 일반 경비는 각자 HP 1로 시작한다. |
| 아이템과 장식 | 권총은 `IInteractable`로 줍고 `SwapShotAbility`로 사용한다. 장식 받침대를 바라보면 줍기 대상이 생기지 않는다. |

## 박동과 검수 자료

| 명중 후 게임 시간 | 화면과 소리 | 실제 카메라 시야각 변화 |
| --- | --- | --- |
| 1초 | 첫 심장·북 소리와 전 화면 박동 | −2.52° |
| 2초 | 같은 리듬에 더 강한 박동 | −3.06° |
| 3초 | 교환한 프레임에 마지막 박동 | −3.60° |

시야각은 박동 뒤 원래 값으로 돌아왔다. 흰 안개가 양쪽 박자 사이에도 잠시 남아 부드럽게 옅어진다. 가장자리 윤곽에는 블러가 걸리고 조준점 주변은 초점을 유지한다. 영상은 실제 B5 카메라의 128개 프레임을 960×540, 30 fps로 기록했다. 소리는 플레이 중 측정한 세 재생 시각과 음량에 게임의 심장·북 음원을 맞춰 합성했다. 검수 시 구역 사이 이동과 조준 방향을 단축하고 줍기·사격·투척 입력은 PlayerInput을 거쳤다.
