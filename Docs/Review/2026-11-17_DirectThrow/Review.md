# 좌클릭 직접 투척 V0.01

2026-11-17 · 작성자 송예찬

E로 준비 자세를 먼저 켜는 단계를 없앴다. 현재 투척용 물건은 좌클릭 누름으로 자동 준비·조준, 버튼 해제로 즉시 투척한다. 짧게 클릭하면 바로1회 던지고, 길게 누르면 궤적을 보다가 놓을 때 던진다. 홀드 시간에 따라 힘을 충전하지 않는다.

| 입력 | 현재 동작 |
|---|---|
| 좌클릭 누름/유지 |E 없이 준비·궤적 조준|
| 좌클릭 해제 |1회 투척|
| R |소지품이 있으면 조준 전/중 모두 위·아래 방식 전환|
| 우클릭 |조준 중 취소, 그 외 소지품이 있으면 확대 토글|
| E |투척 취소 보조키|

취소 후 좌클릭을 계속 누르거나 놓아도 던지지 않는다. 새 클릭부터 다시 시작한다. 같은 프레임의 좌클릭/취소는 취소를 우선한다. InputAction 맵의 비활성화 때문에 발생한 canceled도 버튼을 놓아 던진 것으로 처리하지 않는다.

`PlayerThrow.BeginAim`에서 준비 상태를 자동 시작하고, `ToggleThrowMode`는 소지품을 기준으로 전환한다. `PlayerPresenter`는 E/우클릭 취소를 먼저 처리하며 Attack 액션 활성 상태를 확인한다. 기존 사용자 코드의 이동/시선/앉기/점프와 입력 에셋·프리팹·Animator는 보존했다. 위12/아래6m/s·선2.5/4m와 페이드·선이 닿을 때만 접촉 원 표시도 유지한다.

실제 Mouse/Keyboard 상태 이벤트 → 기존 PlayerInput 콜백 → Presenter/System 경로로34/34 통과했다. 빠른 클릭·동일 프레임 누름/해제·연속3회·길게 유지·R 사전 선택·우클릭/E 취소·동시 입력·확대·컴포넌트/액션 맵 비활성화·물건 교체·빈손·막힌 손·단일 소지품 소비를 확인했다. [원시 검사](validation.txt) · [E 없이 조준한 B5 화면](direct_hold.png) · [최종 편집/콘솔 상태](audit.json) · [기존 파일 보존](preservation.json).

총 사격·손전등·문서 사용은 현재 미구현이다. 이전 E 자세/좌클릭 사용 규칙을 그대로 적용할 수 없으므로 실제 기능 구현 때 기본 사용과 투척의 입력을 정한다. 이번에는 새 사용 키를 임의로 배정하지 않았다.

로컬 저장, 이번 커밋·push 없음. 최신 기획 V0.93을 따른다. 이전 E 필수 흐름과 이전 입력 검수를 현행 동작으로 복구하지 않는다.
