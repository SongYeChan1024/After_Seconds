# B2 설비 운영 동선 재구성 검수 V0.01

작성자 송예찬 · 2026-11-10

사용자가 승인한 점검원·경비 관점의 구조를 B2 전체 12공동에 적용했다. 현재 씬은 `Level_B2_Circular.unity`, 새 계층은 `B2_MachineryNetwork/B2_OperationsLayout`이다. 기존 벽·문·코어3·터널21을 유지하고 내부 설비를 186배치로 다시 구성했다. 이전 설비와 데크는 비활성 상태로 보존했다.

| 공동 | 역할과 배치 | 배치 수 |
|---|---|---:|
| C01 | 원심분리 · 두 공정열 | 19 |
| C02 | 냉각 · 펌프 점검로 | 17 |
| C03 | 배전 · U자 제어반 | 9 |
| C04 | 관제 · 운전석과 후면 정비로 | 12 |
| W01 | 주 전력 · 변압기와 차단반 | 15 |
| W02 | 예비 전력 · 발전기와 연료계통 | 15 |
| W03 | 부품 · 입고·보관·수리·출고 | 18 |
| E01 | 급수 · 축압 탱크와 가압 펌프 | 13 |
| E02 | 공조 · 필터 교체면과 모터 정비면 | 13 |
| E03 | 폐수 · 습식 공정과 건식 기록 | 14 |
| N01 | 환기 · 팬열과 덕트 | 18 |
| S01 | 정비 · 계측 작업대와 수리 인계 | 23 |

C02의 두 펌프열은 중앙에서 운전 상태를 읽고 뒤쪽으로 돌아 정비한다. C01은 공급·분리·냉각을 두 공정열로 묶었다. W03은 입고와 출고 카트 주차를 통로에서 빼고 중앙 이동로를 확보했다. C03/C04에는 젖은 공정 설비를 두지 않고 전기·관제 역할을 분리했다. S01의 정비용 모터는 작업대 위에 놓아 통행을 막지 않게 했다.

상부는 C02의 U형, W02의 L형, E02의 직선 점검 데크, E01의 부분 곡선 데크로 구분했다. 기존 C02–T01, W02–T11/T12, E01–T14/T15, E02–T15/T16의 7개 끝을 유지한다. 공동 높이3.6m와 터널 높이2.42m 사이에는 계단과 수평 참을 둔다. 실제 충돌 검사에서 발견한 난간 간섭과 단차를 보수했다. 데크·계단·지지대에 베벨을 적용하고 LOD와 보행용 충돌을 분리했다.

기존 광원 158개를 유지했다. 공동별 기존 등기구 한 개의 색·밝기만 작업면을 읽기 쉬운 적황색으로 조정했고, 흰 직접광은 0개다. 반사와 가림 정보도 새 배치로 갱신했다.

검증 결과:

- 하부 공동 출입구 32/32, 설비 조작면 186/186 접근 연결 확인. 실제 Controller로 공동 출입구 간 이동도 검사했다.
- 상부 17경로의 Controller 왕복 34/34 통과.
- 기존 복층 터널 19개: 4,910표본, Controller 왕복 76/76 통과. 짧은 T04/T06은 기존 단층이며 출입 연결 검사에 포함했다.
- 실제 Play 6경로, 1,007프레임 진행, 새 게임 오류0. 키보드·마우스 활성 상태 복구.
- 기존 Transform 3,311개 누락0. 보호 파일 26개 동일. 새 그룹의 메시·재질 누락0, 게임 스크립트 추가0.

검증은 통행과 정적 레벨을 대상으로 한다. 경비·CCTV의 실제 순찰/감지, 설비 작동, 문/승강기 동작과 최종 잠입 난이도는 이번 작업에 포함되지 않는다. 전체 아트의 최종 수용은 사용자의 1인칭 검수 뒤 판단한다.

다음 검수는 C02 중앙 점검로 → E02 필터 교체면 → W03 수리대 → E01/W02 상부 접속부 순서다. 현재 씬을 과거 Apply 도구로 재생성하지 않는다. 로컬 저장이며 커밋·push는 요청받지 않았다.

가져오기 잔여 경고: 별도 `_LOD1.fbx` 파일에 `_LOD0`가 없다는 Unity 자동 LOD 이름 경고가 남아 있다. 이 레벨은 씬의 명시적 LODGroup을 사용하며, 최종 재가져오기 후 새 그룹의 LODGroup 190개와 메쉬·재질 참조 누락 0을 확인했다. 모델 형상 오류나 게임 컴파일 오류는 아니다. 내부 노드 이름만 바꾸어도 경고가 남아 변경을 원복했으며, 파일 이름·GUID·메쉬 이름을 보존했다.
