# B5/B4 표면·B4 조명과 성능 검수 V0.02

작성자: 송예찬 · 2026-11-09

바닥과 화물 승강기 사용감이 잘 보이지 않는다는 피드백에 따라 B5/B4 바닥 59개 시각 메시의 재질 14개를 새 파생 재질로 교체했다. 줄눈·불규칙한 마찰·운반 바퀴 자국과 승강기 하단 오염·문턱 마모를 강화했다. 먼지를 깊이 파인 요철로 표현하지 않도록 노멀 강도를 낮췄다. 원래 재질은 보존했다.

벽에도 약한 생활 흔적을 적용했다. B5/B4 벽 88개는 원본과 같은 형상·노멀을 사용하고 도장 면의 UV와 재질만 바꾼 파생 메시다. 하단 먼지와 옅은 마찰 흔적을 중심으로, 상단은 비교적 깨끗하게 유지했다. B5는 더 약하고 B4는 장비 사용감을 조금 더 남겼다. 실제 벽 연결부와 리브 형상은 유지했다. 장비 자체의 별도 패널 전체를 일괄 오염 처리한 것은 아니다.

B4는 중성 작업광과 도장·금속의 반사를 조정하고 16개 방에 정적 반사 프로브를 배치했다. 기존 305개 Light 위치는 같으며 그림자 광원은 305개에서 233개가 됐다. 733개 대상에 원본 근접 메시를 그대로 둔 3단계 LOD를 적용했다. 원거리 LOD 130개는 UV·재질 경계를 고려해 감면했다.

검수 결과:

- B4 기존 Transform 1,865개와 충돌 설정 차이 0, 기존 Renderer 누락 0, 예상 밖 원본 메시 교체 0.
- B5 기존 Transform 4,057개·Light·충돌 설정 차이 0.
- 벽 88개, 1,379,548삼각형의 위치·노멀·서브메시 순서 원본과 동일.
- LOD 연결 누락 0, 재질 누락 0, 원거리 자식에 추가된 충돌체 0.
- 원거리 모델의 퇴화 삼각형 0, 최대 경계 오차 약 7mm. 얇은 면의 스무딩 노멀과 면 방향 차이 115삼각형은 남아 있어 모든 면의 노멀 방향이 완전히 일치한다고 판정하지 않았다.
- Controller 경로 331/331 통과. 벽 후속 변경은 시각 메시만 바뀌었으며 충돌 보존을 별도로 대조했다.
- 실제 Play E02·E03·W02에서 프레임 진행과 W 키 이동 확인, 새 경고/오류 0. W02의 처음 입력 미전달 결과는 성공 판정에서 제외하고 재실행했다.
- 같은 측정 지점에서 E02 렌더 삼각형 약 271만→166만, E03 약 754만→488만. W02 재검사 약 358만. Editor 프레임 시간은 다른 프로세스와 편집 상태의 영향을 받아 배포 빌드 FPS 보장으로 해석하지 않는다.
