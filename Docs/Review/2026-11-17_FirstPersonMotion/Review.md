# 양손 이동·발 표시·착지 미리보기 V0.01

2026-11-17 · 작성자 송예찬 · Unity 6000.4.0f1 · After Seconds

사용자가 요청한 양손 표시, 걷기·달리기 때의 팔 동작, 아래를 볼 때 보이는 다리·발, 오른손에서 첫 접촉점까지 이어지는 선과 원형 표식을 연결했다. [실제 B5 화면 비교](review.html)

## 구현

- 양손은 실제 수평 이동 속도에 맞춰 반대 박자로 움직인다. 정지하면 보간하며 멈추고 조준·확대·앉기에서는 진폭을 낮춘다. 점프와 착지에는 작은 손의 상승/눌림 반응이 있다.
- `FirstPersonLowerBody`는 기존 리그의 본을 공유하는 표시 전용 메시다. 다리·발과 몸통 연결부 4,486삼각형을 포함한다. 원본 FBX·클립·AnimatorController를 바꾸지 않았다. 원본 전신은 그림자를 담당한다.
- 기존 Animator의 `CullUpdateTransforms` 때문에 몸이 시야 밖일 때 걸음 포즈가 멈추던 문제를 `AlwaysAnimate`로 보완했다. 원본 본에 절차적 다리 포즈를 덮어쓰지 않는다.
- 오른손에 든 물체의 중심에서 첫 구체 충돌까지 경로를 예측한다. 표시의 마지막 점은 실제 접촉 표면에 연결한다. `PreviewEnd`는 물리 중심, `PreviewContact`는 표면 접촉점이다.
- 접촉면 방향에 맞춘 원을 표시한다. **원은 예상 접촉 위치를 안내하며 폭발·피해·교환 범위가 아니다.** 좁은 표면에서는 반지름을 줄이고, 원을 지지할 표면이 없으면 숨긴다.
- 취소·방출·아이템 제거·비활성화·시작점 막힘·시간/거리 한계에서는 남아 있던 원과 접촉 정보를 정리한다. 기존 짧은 선 모드는 설정으로 유지한다.

## 직접 확인

`E`로 투척 자세, 왼쪽 버튼을 누르면 경로/원을 표시하고 떼면 즉시 투척한다. `R`은 위/아래 던지기 전환이다. 조준 중 오른쪽 버튼은 취소, 조준 밖에서는 확대다. `W`와 `Shift`, `C`, `Space` 및 아래 보기로 손·발 동작을 확인할 수 있다.

## 검증 결과

[실제 입력 검사](play_validation.txt)는 **40/40 통과**, 197→1,088프레임 동안 실행됐다. 걷기/달리기 속도 약5/7.5m/s에서 양손 반대 위상 상관계수 -1.000, 오른손 앞뒤 변화량 약6.9/11.7cm를 측정했다. 달리며 조준할 때는 약1.8cm로 줄었다. 기존 애니메이션의 두 발 간 앞뒤 간격도 걷기와 달리기에서 변화했다.

실제 방출 후 첫 바닥 접촉과 원의 예측 중심 차이는 약6.3cm였다. 구체 충돌의 고정 물리 간격과 실제 PhysX 접촉 시점 차이가 있으므로 정확한 최종 정지점 보장은 아니다. 바닥·벽·경사면 방향, 취소 후 미발사, 1회 방출, 소지 표시 숨김, 제한 길이/시간의 가짜 착지 방지, 시작 겹침 차단, 아이템 제거·비활성화를 포함했다.

[최종 B5 화면 기록](final_visual.txt)에서 움직이는 동안의 속도와 양손 화면 좌표를 다시 확인했다. 서기·걷기·달리기·앉기·아래 보기·확대 조준·위 보기를 촬영했다. 확대 조준에서도 양손이 화면 안에 있다. 몸통 경계는 원본의 기하를 포함하도록 보완하고 메시 인덱스 버퍼까지 갱신했다.

[최종 에디터 검사](final_audit.json): 콘솔 오류/경고0, 누락 스크립트/필수 참조0, 몸 본53개 누락0. B5 편집 모드·씬 변경 없음이며 검수용 백그라운드 실행을 껐다. Unity 직렬화 프리팹의 빈 문자열 뒤 공백은 기본 직렬화 형식대로 보존했다.

첫 검사에서 발견한 팔 도달 거리와 Animator 갱신 문제를 보수했다. [첫 검사 기록](play_validation_initial.txt)은 이력이며 최종 결과가 아니다. 앉은 자세에서는 기존 클립의 무릎에 한쪽 발이 가려질 수 있어, 하체와 한쪽 발 이상이 보이는지 확인했다.

## 보존 및 범위

이번 단계 시작 시점의 게임 스크립트/.meta 54개 중 손 표시·손 설정·투척·투척 설정 C# 4개만 변경했다. 나머지50개는 해시가 같다. 사용자가 수정하던 Presenter·입력·Motor·Look·AnimationSystem을 보존했다. 프리팹의 기존 fileID138개도 모두 유지했다. 추가된 메시의 본 참조 때문에 stripped 참조 항목이 늘었으며 새 표시 오브젝트는 1개다.

현재 모델은 기존 회색 더미를 재사용한다. 전용 손/의상 모델, 자연스러운 물체별 쥐기 포즈와 모션 캡처 수준의 투척 애니메이션은 별도 에셋 작업이다. 하체는 기존 걷기·달리기·앉기 클립을 따른다. 별도의 전신 점프/착지 클립을 새로 연결한 것은 아니다. 투척 물리 프로필은 현재 중심 구체 1개인 시험용 공을 지원하며 반사 이후 경로·미래 이동 표적·다른 형상은 지원하지 않는다.

3초 교환·인벤토리·AI·공장/다른 층은 이번에 확장하지 않았다. 로컬 저장이며 이 단계의 커밋·push·블로그 게시는 하지 않았다.

## 제작·재검수

`SourceAssets/FirstPersonMotion/BuildBody.cs`는 대상 프리팹/설정/표시 메시를 Unity API로 연결한다. 기존 `.meta`를 유지하며 메시 인덱스 버퍼를 명시적으로 갱신한다. 후속 수작업으로 조정한 설정을 덮어쓰므로 필요할 때 수정 범위를 읽고 실행한다.

`ValidatePlay.cs`는 임시 플랫폼에서 동작을 검증하고 정리한다. `CaptureFinal.cs`는 실제 B5 화면을 기록하며 검수 중에만 입력 설정 복제본을 사용해 Game View 포커스에 따른 입력 누락을 방지하고 원래 설정을 복원한다. 씬은 저장하지 않는다.
