총 추가 설비 97배치, 신규 메자닌 3개, 상부 연결 공동 4개, 연결 터널 6개·접속부 7개다. 터널 데크 2.42m에서 공동 데크 3.60m로 올라간다. 터널은 크라우칭, 공동 데크는 서서 이동한다. 연결한 끝의 기존 하부 계단은 상부 직결 구조로 대체하고 다른 끝은 유지했다.

공급·회수 배관을 공동 공정 설비까지 연결하고 볼트·플랜지·압력계·난간·개방형 그레이팅·철골 받침을 표현했다. 제조 모서리는 베벨, 멀리서는 LOD를 사용한다. 신규 모델/LOD 64개, 이번 배치 아래 LOD 그룹 117개다. 조명은 158개를 유지했으며 흰 직접 광원은 0개다. 새 데크와 겹치던 펜던트 9개는 6.3m로 올리고 현수선 길이를 맞췄다.

검수 결과:

- 기존 19개 복도: 하부 2,848·상부 2,062표본 통과, Controller 76/76 왕복 통과. 상부 2,062표본 모두 서기 차단 확인.
- 상부 연결 동선과 기존 C02 계단까지 23경로·2,227표본·Controller 46/46 왕복 통과. 단차와 난간 개구부를 보수했다.
- 전체 공동/코어의 문과 장비 접근 283/283 통과. 접근 공간이 좁았던 모터 받침과 정비 카트의 방향을 수정했다.
- 실제 Play 4검사, 1,595프레임 통과: T14→E01 상부 진입, E02 내부 계단 상승, E02→T16 하강, T14 하부 보행. 새 게임 오류 0, 실제 Mouse/Keyboard 활성 유지.
- 기존 Transform 2,994개 누락 0. 이동한 기존 항목은 펜던트·광원·현수선 27개다. 구형 통로 6개와 C02 구형 난간은 비활성 원본으로 보존했다.
- 배치 97/97 일치, 누락 메시/재질 0. 장비–배관 겹침 2건은 탱크 접속부의 의도한 체결이다. 통행 장애로 판정하지 않았다.

기존 C02 계단은 실제 단차 충돌을 사용하므로 직선 경사로 높이와 비교하지 않고 각 표본의 실측 발판 높이를 사용했다. 무릎 아래의 정상 계단 접촉은 Controller의 stepOffset/skinWidth 범위로 평가하고 상체·머리 여유 및 실제 왕복 이동을 검사했다. 새 통로는 별도 연속 보행 충돌을 사용한다. 정적 반사37개와 가림 데이터를 현재 배치에 맞춰 다시 베이크했다.

Player 씬·런타임 게임 코드·Animator·다른 층은 수정하지 않았다. 문/설비 작동, AI 감시와 게임 난이도, 최종 FPS 목표 검증은 이번 정적 레벨 검수 범위 밖이다. 시각적 밀도와 어두운 붉은 분위기는 사용자 확인 후 필요한 위치만 조정한다. 로컬 저장이며 이번 작업의 커밋·push는 요청받지 않았다.
