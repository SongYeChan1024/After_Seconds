**감시·교환 기준 확정(2026-11-10).** [메인 기획서](../../../../AfterSeconds_메인기획서.md)을 따른다. 열린 그레이팅은 상하 시야를 통과시키고, 굵은 배관·실제 불투명 설비를 엄폐로 쓴다. 연속 보행 Collider를 그대로 불투명 감지 차단면으로 쓰지 않는다. B안 교환은 명중 3초 뒤 양쪽의 현재 자세·몸 크기·지지 바닥을 검사하며, 앉은 플레이어 자리로 서 있는 경비가 들어가지 못하면 해당 교환 전체를 취소한다. 이 기준은 기획 확정이며 감지·교환 코드는 후속 구현이다.

복층은 배관 정비를 위한 구조다. 상부 양옆의 공급·회수 배관과 신호선, 차단 밸브·압력계·플랜지에 접근한다. 중앙 그레이팅으로 앉아서 통과한다. 최종 조명은 원형 보호망등과 금속 갓 펜던트이며 활성 광원을341→158개로 줄였다. 이 수에는 약한 간접광12개가 포함된다.

최신 연결 기준은 [공동 상부 연결 도면](B2_공동상부연결.png)이다. C02 기존 메자닌과 E01·E02·W02 신규 원형 정비 데크를 T01·T11·T12·T14·T15·T16의 7개 끝에 연결했다. 터널 데크2.42m에서 공동3.60m로 계단을 통해 이동한다. 연결한 끝의 기존 하부 계단은 대체하고 나머지 끝과 다른 통로의 진입은 유지한다. 상부 공급/회수 배관도 공동 설비에 연결했다.

[기존 복층 단면 도면](B2_복층통로.png)은 터널 단면 참고용이며 양 끝 계단·C02 분리 설명은 V0.02 당시 기록이다. 통로19개의 폭1.50m 상부는 앉아서, 하부는 서서 이동한다. 짧은 T04·T06은 단층이다. 상부 유효 높이는 약1.30~1.43m이며 기존1.20m 크라우칭을 사용한다.

[연결도](B2_연결도.png)와 [실제 배치 명세](as_built_layout.json)를 기준으로 Level_B2_Circular 씬을 연결했다. 공동12개·계단/승강기 코어3개·통로21개다. 공동 중심과 연결 관계는 유지하고 T01/T07/T08/T19/T20의 진입부를 곡선으로 조정했다.

통로는 내경5m 원형 금속 외피, 두께0.18m, 바닥4.2m, 천장3.85m다. 구조 플랜지/볼트와 측면 설비 배관을 유지한다. 조명은 어두운 철색 공간과 붉은 실물 등기구를 기준으로 바꿨다. 흰 작업등 발광면/광원을 함께 붉게 바꾸고 상부 머리 공간에 있던 천장등은 보호망·렌즈·벽 브래킷이 보이는 측면 조명으로 교체한다. C02의 기존3.6m 그레이팅 메자닌은 통로의2.42m 데크와 구분한다.

장비144배치와 C02 기존 장비, 연결 헤더·공조 접속·배선29배치에 더해 공동 설비97배치를 추가했다. 최신 검수는 [공동 밀도·연결 기록](../../../../Review/2026-11-10_B2_DomeNetwork/Review.md)을 따른다. 기존 [복층 통로 검수](../../../../Review/2026-11-10_B2_DetailMezzanine/Review.md)와 [전체 연결 검수](../../../../Review/2026-11-09_B2_FullFloor/Review.md)는 각 단계 당시 기록이다. 기존 Excel·PDF·SVG에는 최신 복층 연결과 추가 배치가 반영되어 있지 않다.
