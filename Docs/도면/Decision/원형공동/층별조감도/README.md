# After Seconds 층별 실내 조감도 안내 V0.03

**2026-11-11 사용자 정정.** 실험체의 정상 생활·시험 범위는 B5·B4이며, B4→B3 상행 경계부터 실험체 진입을 막는다. B3·B2·B1·1F는 실험체의 정상 활동 구역이 아니다. 플레이어가 상층으로 올라가는 것은 이 경계를 뚫는 탈출 상황이다. ## 가구와 작은 부품 읽기

좌표 도식의 큰 가구는 청회색, 별도 구성품은 황갈색 계열입니다. 침대·사물함·작업대·서버 랙의 배치 ID를 엑셀에서 찾고, 부모 배치 ID로 필터하면 침구·식기·세면용품·기록지·케이블 등의 세부 명세를 확인할 수 있습니다. 조립 기준과 그 내부 부품 수량을 실제 장비 대수로 합산하지 않습니다.

생성 그림은 생활 흔적과 외형을 보여 주는 배치 참고입니다. 생성 그림에 표현된 개별 소품 수·칸막이·방향은 정확한 시공 도면이 아닙니다. 정확한 좌표·치수는 현재 배치 JSON과 엑셀을 우선하고, 소품의 상판·선반·랙 슬롯 정합은 실제 모델에 맞춰 마무리합니다. B3 이미지는 프랍을 읽을 수 있게 노출을 올린 표현이며 게임의 구역별 소등 방향을 변경하지 않습니다.

## 기준과 검증

Decision의 배치 설계 V0.03을 사용했습니다. B2 +3.6m 그레이팅 메자닌과 두 계단, B4 +2.5m 관찰 데크, 층별 최신 색감을 반영했습니다. 지하 공동은 각 층에서 독립된 원형 반구이고, 지상은 일반 폐공장입니다. 기존의 생활 자리 가안과 공간 ID를 바꾸지 않았습니다.

6층·67개 비코어 실내 공간 포함 여부, 원본 좌표·품목 참조와 PDF 페이지 경계를 확인했습니다. 조감도는 전체 제작 완료나 실제 Unity 메시·충돌·AI 시야 검증을 뜻하지 않습니다. 이 작업은 문서와 그림 추가이며 현재 씬·게임 코드를 변경하지 않았습니다.
