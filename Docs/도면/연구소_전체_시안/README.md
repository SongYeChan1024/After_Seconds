2026-10-26. 내장 ImageGen으로 생성한 게임 환경 개념 시안. 기존 기획서와 방별 SVG를 대체하지 않는다.

- `01_외관과_단면_V0.01.png`: 물류창고 위장 외관, 지상 1층과 지하 5층 단면.
- `02_전체층_평면도_V0.01.png`: 1F·B1·B2·B3·B4·B5 평면 구성 제안.

기획서의 층별 기능과 방 1~10 배치를 바탕으로 관찰 유리, 직원 동선, 보안 전실, 화물 리프트, 설비 공간을 추가했다. 48×32m 외곽과 층고 등 표시 수치는 새 가안이다. 이미지 안의 축척 표기는 출력 크기와 연동되지 않으므로 실측에 사용하지 않는다.

이미지 생성 특성상 문·동선·실 번호·설비의 세부 정합성은 보장되지 않는다. B5 셀 수와 피험체 번호는 확정 설정이 아니다. 냉각조를 우회하는 길, 직원 통로를 통한 퍼즐 건너뛰기, 층별 연결부와 기존 방 치수는 SVG 재설계 단계에서 검토해야 한다. 외관 표지의 연구소 이름은 위장 설정에 맞춰 일반 물류회사 표지로 바꿀 수 있다.
