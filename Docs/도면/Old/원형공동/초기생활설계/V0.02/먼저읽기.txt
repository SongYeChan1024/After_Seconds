사람의 하루를 먼저 생각한 설계
실험체: 잠 → 화장실·세면 → 식사 → 환복 → 이송·검사 → 실험 → 회복 → 생활실
연구원: 숙소 → 위생·환복 → 식사 → 계획 → 실험·관찰 → 분석·기록 → 휴식 → 숙소
경비원: 숙소 → 교대·장비 수령 → 관제·순찰·이송 지원 → 식사·대기 → 인계 → 숙소
지원인력: 물자 반입 → 보관·배분 → 급식·리넨·청소 → 설비 점검 → 폐기·회수

1. 도면 PDF부터 읽기
앞쪽은 시설 구성·층간 조감도·단면입니다. 이어 지하 각 층의 전체 배치와 핵심 구역 상세가 나옵니다.
A-16은 역할별 하루, A-17은 관측 데스크와 서버, A-18은 격리 생활 모듈입니다.
지하 5개 층은 각각 독립된 원형 공동과 터널로 구성됩니다. 지상은 폐공장입니다.
지하 공동 63개, 전체 외곽 약 270×180m 가안입니다. 중앙 핵심 구역부터 단계적으로 제작하세요.

2. 엑셀에서 공간 하나 고르기
설계안내 → 생활동선 → 공간프로그램 순서로 읽고 원하는 공간을 고릅니다.
예: B5-W01은 다른 실험체 생활실, B1-W03은 연구원·지원인력 숙소,
B1-E03은 경비 숙소·교대 공간, B3-E02는 주 서버실입니다.
생활 자리 가안: 다른 실험체 8칸 + 플레이어, 연구원·지원인력 16침상, 경비 8침상.
이 수는 기본 비품 계획을 위한 가정이며, 시설 최대 수용 인원이나 확정 입주 인원이 아닙니다.

3. 공간별 물건과 세부 구성 확인하기
배치구성목록에서 층·공간 ID로 필터합니다.
프랍제작목록에는 145종의 품목, 제작 우선순위, 크기 가안, 기존 에셋 경로와 외형 참고 링크가 있습니다.
배치구성목록 3,264행은 가구·설비·조립 기준·구성 부품을 합친 명세입니다.
조립세트의 부모 배치 ID로 필터하면 데스크·생활 모듈·침대·서버 랙 등에 속한 작은 물건을 확인할 수 있습니다.
침구, 식기, 환의, 수건·비누·휴지, 청소도구, 기록지, 케이블, 충전기까지 포함했습니다.
큰 세트와 구성품 수량을 합쳐 실제 장비 대수로 해석하면 안 됩니다.

4. 제작·배치 상태 기록하기
새로 배치한 항목은 '배치 완료', 기존 Prefab에 이미 들어 있는 구성품은 '기존 포함'으로 표시합니다.
제작목록과 조립세트의 처리·남은 수량이 자동으로 갱신됩니다.
좌표는 모두 층 루트 기준이며 X=동쪽, v=남쪽, Unity Z=-v입니다.
엑셀의 Unity Y는 해당 층 안의 설치 높이입니다. 층 루트 Y는 공간프로그램을 따릅니다.
부모 ID는 소속을 나타내며 부모 로컬 좌표가 아닙니다. 실제 부모 아래로 옮길 때는 월드 위치를 유지하세요.
행을 새로 추가하면 집계 수식의 범위도 확장해야 합니다.

검토 범위와 남은 상세 설계
원형 공동의 평면 중첩, 의도하지 않은 공동을 통과하는 터널, 큰 가구·장비를 반영한 핵심 경로를 확인했습니다.
저장된 엑셀의 좌표·수량 수식과 상태 집계를 검증했습니다.
작은 소품 좌표는 조립 초안입니다. 실제 모델에 맞춰 상판·선반·랙 슬롯 위치를 정리해야 합니다.
내부 칸막이·문 여유·계단 메시·난간·배수·환기·AI 시야·NavMesh·구조계산은 후속 정합 대상입니다.
층을 건너뛰지 않게 하는 출입 구획은 제안했으며 잠금 해제 방식은 아직 정하지 않았습니다.
분위기 이미지는 외관 참고입니다. 정확한 위치·치수·수량은 도면과 엑셀을 따릅니다.
이 자료는 기존 사각 평면을 대체하는 별도 설계 제안이며 Unity 프로젝트에는 적용하지 않았습니다.
