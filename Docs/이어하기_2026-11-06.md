## 이어갈 때 주의

로컬 변경을 보존한 뒤 `git pull --ff-only`를 실행한다. `BuildB4Scene.Build`는 새 B4 씬이 이미 있으면 중단하도록 만들었다. 완성된 씬에 제작기를 무작정 재실행하지 않는다. Blender 건축 생성기는 기존 건축 FBX를 다시 출력하므로 먼저 원본/씬을 백업하고 변경 범위를 정한다.

검은 화면/ReflectionProbeManager 오류가 다시 나오면 조명 베이크 참조를 확인한다. 이번에는 새 씬의 복사된 LightingData를 분리하고 B4 전용 정적 반사를 생성해 해결했다. 원본 B5의 조명/모델을 삭제하거나 Packages를 업그레이드해 해결하지 않는다.

Unity 연결은 로컬 CLI/Pipeline으로 실제 명령 실행을 확인했다. 예전 unityMCP8080 설정 존재와 현재 CLI 연결 성공을 혼동하지 않는다. CLI 검수는 일시적으로 Run In Background를 켰다가 false로 복구했다. 실제 게임 씬·코드와 외부 제작/검수 스크립트를 구분한다.

검수 중 생성된 `ProjectSettings/Packages/com.unity.pipeline/EditorPipelineConfig.json`은 로컬 미추적 파일로 남아 있다. 백그라운드 실행 관련 옵션3개는 모두 false다. 마지막 정리 명령이 자동 승인 검토에서 `blocked by policy`로 거절되어 삭제하지 않았다. 작업 전부터 있던 사용자 `GatewaySettings.asset`과 구분한다.
