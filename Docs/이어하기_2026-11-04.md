## 집 PC의 도구·권한 설정

프로젝트 파일은 Git으로 이어지지만 대화 전체, 로그인, MCP 연결, 사용자 설정은 자동으로 옮겨지지 않는다. 학원 PC의 토큰·인증 파일을 저장소에 복사하지 않는다. 집에서는 현재 연결된 Unity 도구와 대상 프로젝트가 맞는지 확인한 뒤 사용한다.

학원 PC는 사용자 설정과 Projects 설정을 아래 시작 기본값으로 저장하고 새 실행 검사에서 `Never`·`unrestricted`를 확인했다. 이 설정 파일은 After_Seconds 저장소 밖에 있으므로 이번 push로 집 PC 설정이 바뀌지는 않는다. 집에서도 같은 기본값을 원하면 집의 `~/.codex/config.toml` 최상위에 저장하고, 프로젝트 `.codex/config.toml`이나 실행 옵션이 다른 값을 덮어쓰는지도 확인한다.

```toml
approval_policy = "never"
sandbox_mode = "danger-full-access"
```

현재 열린 세션과 다음 새 실행의 권한을 구분한다. 외부 앱·브라우저 승인과 로그인은 별도다. [공식 시작 기본값 안내](https://learn.chatgpt.com/docs/sandboxing)를 참고한다.
