## 현재 상태

B5~1F의 6개 층에 공간·환경 초안이 있다. 앞선 11월 3일 검사에는 환경·소품 48종을 현행 프리팹 또는 재제작 모델로 사용한 기록이 있다. 오늘 B2 원래 직관·엘보 외형은 연결 관망으로 대체했으므로 48종 모두에 현재 활성 Renderer가 있다고 재검증한 것은 아니다. 전층 배치·설비 연결·메시 품질·실제 플레이가 완성됐다는 뜻도 아니다.

이번 작업은 B2 배관 연결과 1F 셔터·외장 코너 보수까지 마감한다. 전층 추가 배치와 검수, 프랍 수급, 게임 기능, 실제 플레이 테스트, 난이도 조정은 다음 작업 세션에 이어간다. 새 유료 에셋 생성은 하지 않았다.

## 시작 순서

1. 작업 트리와 프로젝트 지침을 확인하고 `git pull --ff-only`로 최신 상태를 받는다. 커밋되지 않은 기존 작업은 덮어쓰지 않는다.
2. 이 문서와 `AGENTS.md`·`CLAUDE.md`를 읽는다. 이전 B5 제작·반입의 자세한 이력은 [11월 3일 이어하기](이어하기_2026-11-03.md)를 따른다.
3. Unity 프로젝트는 `Unity/After_Seconds_Build_V0.01`, Unity 6000.4.0f1 / URP 17.4.0을 유지한다.
4. `Assets/Afrer_Seconds/01.Scenes/Stage/`에서 B2·1F 수정 구역부터 확인한다. 각 층 씬에는 플레이어·카메라가 있으므로 **한 번에 하나씩** 연다. 다른 층이나 `Player.unity`를 동시에 로드하지 않는다.
5. 고정 렌더·구조 검사와 실제 키보드 플레이·퍼즐 완주를 구분한다. 실제 플레이 테스트는 아직 하지 않았다.

## 보존할 B5 최신 상태

시작 포드는 사용자 위치 `(0,0,10.32)`·스케일 `(3,2,3)`을 기준으로 한다. Room01은 천장 아래7.2m이며 사람 크기의 침구·식사·수납·위생·검사 모니터가 있는 생활·실험형 공간이다. 경비는 돔 밖 `(0,0,5.064)`에 둔다. 내부 중앙에는 얇은 링 펜던트를 매달았고 구형 돔 밖 중앙 등은 껐다. 바깥 천장 조명4개는 유지한다.

배식구는 실제 개구·전달함·독립 문 피벗·충돌과 앞뒤가 동일한 양면 마감을 갖춘다. 저장 상태는 닫힘이다. 입력 개폐·잠금·배식·탈출 동작은 아직 없다. 예전 작은 포드·흰색 뒷면 장식을 최신 상태로 되돌리지 않는다.

사용자가 뒤집은 천장 방향, Player V0.3 리깅·Animator, `SampleScene`과 독립 이동 검증용 `Player.unity`를 보존한다. 치수·충돌·안팎 검수는 [생활형 포드](검수/2026-11-03_Subject_Habitat/생활형_포드_검수.md)와 [돔 내부 조명](검수/2026-11-03_Dome_Interior_Light/돔_내부_조명_검수.md), [이전 이어하기](이어하기_2026-11-03.md)를 따른다.

## 1F 셔터·외장 코너 교체

기존 생성 모델의 셔터·코너 표면이 찌그러져 보이는 문제를 보수했다. 원본 FBX를 보존하고 기존 모델 프리팹에서 새 재제작 모델을 참조한다. 기존 프리팹 GUID와 원본 좌표계의 경계상자(native bounds)를 유지했으며 실제 1F 씬 렌더로 교체 외형을 직접 확인했다. 기존 씬 배치와 Collider는 보존했다.

Unity 경로는 `Assets/Afrer_Seconds/` 기준이다.

- 셔터: `05.Model/Environment/1F/Env_LoadingShutterWall_Rebuilt.fbx`.
- 외장 코너: `05.Model/Environment/1F/Env_ExteriorCorner_Rebuilt.fbx`.
- Blender 원본: 저장소 `SourceAssets/1F_Facades_Rebuilt/`.

외형 교체를 문 작동이나 출구 기능 구현으로 기록하지 않는다. 다음 세션에는 플레이어 눈높이에서 외벽 접합·셔터 앞뒤·중앙 출구를 다시 확인한다.

## B2 배관 연결

이전 B2는 직관·엘보·밸브가 각자 떨어져 있어 설비 노선으로 완성되지 않았다. 오늘 Room07·Room08의 공급·회수 주 배관4개와 Room07 설비 연결4개, HVAC 연결2개를 합친 10개 경로를 연결 관망으로 제작·배치했다. Room07 주 배관 높이는3.38/3.78m, Room08은5.05/5.50m다. 기존 밸브·게이지 외형을 각각2개 복제해 연결에 사용했다.

시각 프리팹은 `Assets/Afrer_Seconds/05.Model/Environment/B2/B2_CompletePipeNetwork_20261104.prefab`이며 절차 메시12개를 같은 폴더에 둔다. 기존 배관 루트6개는 삭제하지 않고 Renderer만 껐다. 장비 끝단은 실제 삼각형 표면에 적중시킨 뒤12cm 삽입해 떠 보이는 접속을 보정했고 최종 실제 씬 렌더로 확인했다.

새 Collider·런타임 Behaviour는0개, 보호 구역7곳 침범은0건이다. 절차 메시의 열린 경계·과다 사용 모서리도0건이다. 전체6층에서 기존 Collider와 Transform 보존을 확인했다. 검수 중 Cinemachine 자동 추적으로 직렬화된 좌표1항목은 원본으로 복원한 뒤 최종 검사를 통과했다. 이는 외형과 구조 검증이며 배관 작동이나 실제 퍼즐 플레이 검증은 아니다.

Room07의 구덩이에 다리를 놓거나 건너편을 교환 가능한 프랍으로 채우지 않는다. Room08의 단상·뒤쪽 투척 통로·해치를 장식 설비로 막지 않는다. 다른 층 배관을 같은 기준으로 완료했다고 해석하지 않는다.

## 전층 메시 검수의 현재 범위

기존 렌더·소스 접촉표와 반입 기록으로 검토 후보를 정리했다. 오늘 새 6층 렌더를 전부 찍어 검사한 것은 아니다. 소스 토폴로지 검사에서 구멍·교차·유효하지 않은 UV가 없더라도 표면이 접히거나 베이크가 왜곡돼 보일 수 있다.

우선 확인할 대상은 다음과 같다.

- `Props/Common/Props_LaboratoryWorkbench`: B5·B3·B1 각1개. 기존 B1 렌더와 소스 프리뷰의 상판·옆판에 큰 삼각형 접힘/음영이 보인다. 정점 변형과 재질 베이크의 기여는 근접 비교가 필요하다.
- `Environment/Common/U04_DuctStraight`: B4·B1·1F 각3개. 소스 HIGH 대비 2476tri 감량 모델의 넓은 면·모서리가 울어 보인다. 실제 플레이 거리에서 결함으로 보이는지는 미확인이다.
- B5 건축 표면 접촉 후보26쌍: 에어록·계단·냉각조 가장자리 등을 확인한다. 숨은 외부 접촉도 섞여 있으므로 모두 깜박임 결함으로 세지 않는다. [이전 접합 검사](검수/2026-11-03_B5_Clinical_Tone/surface_overlap_audit.json)를 따른다.

새 근접 렌더와 카메라 이동으로 실제 보이는 파손·깜박임을 선별한다. 필요하면 무재질·Normal 끈 화면과 비교한다. 원본 고밀도 모델을 무조건 다시 쓰거나 전 모델을 일괄 리메시하지 않는다. 프랍 종류가 한 번 놓인 상태와 용도·동선에 맞춘 배치 완성을 구분한다.

## 다음 작업 세션의 우선순위

3. **용도·동선별 추가 프랍 목록과 수급·배치.** 기존 프랍부터 기능별 묶음으로 재배치한다. 생활·관측·샘플 보관·기계·실험·검문 공간에서 부족한 종류·수량·크기를 정리한다. 새 유료 생성은 구체적인 목록을 보여 주고 승인받은 뒤 진행한다.
4. **플레이어·에너미 기능.** 분석 후 의사코드 → 코딩 → 주석 순서로 구현·검토한다. 직접 작성과 도구를 통한 작성 모두 같다. A/B안은 아직 확정하지 않았으므로 한쪽을 확정 규칙으로 구현하지 않는다. 기존 이동·Idle/Walk 연결과 핵심 예약·교환·경비 기능의 미구현 상태를 구분한다.
5. **실제 플레이 테스트.** 시작 포드부터 각 방의 동선·조작·시야·실패·재시도를 확인한다. 고정 렌더와 충돌 스크립트 통과를 퍼즐 완주로 대체하지 않는다.
6. **난이도 곡선 검토와 수정.** 구간별 완주 시간·실패 횟수·실패 원인·규칙 이해 여부를 기록한다. 이동·조준에서 생기는 불편과 퍼즐 자체의 어려움을 구분한 뒤 새 요소를 소개하는 순서·경비와 시야·재시작 부담을 조정한다. 실제 테스트 전에 확정 난이도 수치를 만들지 않는다.

특정 날짜로 예약한 일정이 아니라 다음 작업 세션에서 위부터 이어갈 순서다. 기획의 수치·규칙은 이번 환경 마감에서 변경하지 않았다.

## Git·Editor 마감 위치

After Seconds는 `main`의 `b1c88a2`를 기준으로 작업했다. 이번 Unity·문서 변경과 앞선 로컬 환경 작업은 이 문서가 포함된 환경 마감 커밋으로 함께 관리한다. 대상은 6층 환경 배치·기존 에셋14종 추가 반입, B5 생활형 포드·양면 배식구·내부 조명, B2 연결 관망·1F 외장 교체, Blender 원본·검수 자료·기획 및 이어하기 문서다. 런타임 게임 코드·Packages·ProjectSettings는 바꾸지 않았다.

다음 세션에는 `git pull --ff-only`와 작업 트리를 먼저 확인하고 원격 `origin/main`과 현재 커밋을 비교한다. 새로운 로컬 변경을 `reset --hard`나 `clean`으로 지우지 않는다. 작업 시작 사본과 임시 제작 스크립트는 Git에서 제외한 `tmp/B2_Pipes_20261104`, `tmp/1F_Facades_20261104`에 보관했다. 재현에 필요한 Blender 원본과 Unity 에셋·검수 기록은 커밋 대상에 포함했다. 검사용 Editor 코드는 Assets 밖으로 보관했고 마지막 확인 씬은 B2다.

블로그의 두 글·이미지3장은 별도 저장소 `Kasil_DevLog`의 커밋 `3471416`으로 `main`에 반영·push했다. 애프터 세컨즈의 원격 반영과 혼동하지 않는다. 다음 세션은 위 우선순위의 수정 B2·1F 재확인부터 시작한다.
