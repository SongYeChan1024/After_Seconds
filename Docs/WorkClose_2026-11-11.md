# After Seconds 11월 11일 작업 마감과 이어하기 V0.01

작성자 송예찬 · 2026-11-11

사용자가 오늘 구현 전체의 커밋·push와 블로그 일일개발일지·데일리로그 작성을 요청했다. **다음 작업은 [B1 전체 실내 구획 재설계](B1_실내구획_재설계_할일.md)**다. 회의장만의 문제가 아니며 현재 B1을 최종 완성·수용 상태로 기록하지 않는다. 재설계는 이번 마감에서 시작하지 않았다. 아래와 별도 검수 자료의 ‘push 미요청/미실시’는 각 제작 단계 당시 상태다.

## 이어서 시작할 때

1. 로컬 작업을 확인하고 `git pull --ff-only`로 최신 main을 받는다. 블로그는 별도 저장소다.
2. 이 문서 → [B1 재설계 할 일](B1_실내구획_재설계_할일.md) → [현재 B1 검수](Review/2026-11-11_B1_StaffData/Review.md) 순서로 읽는다.
3. Unity **6000.4.0f1**로 `Unity/After_Seconds_Build_V0.01`을 연다. 자동 버전 업그레이드는 하지 않는다.
4. 최신 씬은 `Assets/Afrer_Seconds/01.Scenes/Stage/Level_B1_Circular.unity`다. 이전 제작·Apply·Resume 도구를 현재 씬에 일괄 재실행하지 않는다.

## 검증과 한계

- 전체 깊이 충돌 보수의 저장 메시 3,326개 검증 오류 0. 정밀 재검사 범위에서 0.05mm 허용오차를 넘는 잔여 내부 겹침 0.
- B2 프랍 보수 후 194개 배치 루트와 충돌체 유지. 최종 펌프의 근접·양쪽 외형·LOD1을 비교했다.
- 최종 B1 CharacterController **260/260** 통과. 통로 왕복·방 출입·작업/회의 좌석 접근·18m 계단 왕복을 포함한다.
- 실제 Play C01·C02·C05·N01에서 프레임 진행과 입력 이동 확인, 새 경고/오류 0. 최종 회의장 적용 후 C05 재검사도 통과했다.
- B1 메시·재질·스크립트 누락 0, 배치 계획 198개와 저장 씬 일치. 기존 136개 배치 Transform 유지.
- 직원/데이터 보수 전체와 최종 C05의 깊이 충돌 검사 통과. 불투명 평면 0.005m² 이상, 0.05mm 정밀도와 상호 배타적 LOD를 구분한 범위다. 모든 미세 면·투명/스킨드 면·모든 시점의 보증은 아니다.
- B1 반사 16개·가림 데이터 갱신, LOD 328그룹·활성 광원 209개. 이 수치는 최종 빌드 성능 합격을 뜻하지 않는다.
- B1 제작 이후 보호 파일 178개 해시 일치: 다른 층·B2 펌프·게임 C#·Player·Animator 보존. 오늘 앞선 전층 시각 메시 보수와 구분한다.

현재 B1은 용도와 가구를 맞춘 정적 제작 상태다. 큰 돔의 빈 공간, 실내 구획, 생활 프라이버시, 업무 흐름, 통과 길과 체류 자리의 분리가 부족하다. **통행 통과를 전체 층의 디자인 완료로 해석하지 않는다.**

문·CCTV·승강기 작동·에너미 AI·층간 전환은 미구현이며 게임 코드는 사용자 주도로 진행한다. 프로젝트 원본 용량과 실행 시 RAM/VRAM 요구량도 구분해야 한다. 권장 사양의 확정은 빌드 측정 후로 남긴다.
