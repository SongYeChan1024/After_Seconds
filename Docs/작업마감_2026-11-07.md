## 이어서 볼 기준

사용자가 오늘 작업 종료와 블로그 두 글 작성, After Seconds 커밋·push를 요청했다. 이 문서를 포함한 마감 커밋이 11월 7일 실험동 작업의 기준이다. 아래 단계별 검수 문서의 ‘커밋/push 미실시’는 각 단계가 끝난 당시의 기록이다. 최신 원격 반영 여부는 `git fetch origin` 후 현재 브랜치와 `origin/main`을 비교한다.

- 작업 씬: `Unity/After_Seconds_Build_V0.01/Assets/Afrer_Seconds/01.Scenes/Stage/Level_B5_Circular.unity`.
- Unity 6000.4.0f1 / URP 17.4.0. C01의 사용자 호칭은 **실험동**.
- 마지막 검수 상태: 편집 모드, 씬 저장 완료, 플레이어 `(-9.2, -81.36, -10)` / 회전 0, 백그라운드 실행 override 해제.
- 실험동 문은 열린 상태. 모니터 화면은 정적 텍스처다. 개폐·화면 갱신·광원 스위치 등 게임 C#과 Animator 동작은 추가하지 않았다.
- 사용자가 직접 조정한 `Worklight_52`의 Transform과 광원 수치는 보존했다. 등기구 없는 보조광이라 Light 컴포넌트는 비활성 상태다.
- 전체 구조는 일반 공동12·이동 코어3·복도19이며, 전체 아트 완료 판정은 **0/34**다. 실험동 최종 사용자 시야 검수와 안내선 마감은 남아 있다.

## 다음 작업 순서

1. 회사/다음 PC에서 `git pull --ff-only` 후 이 문서와 [이어하기](이어하기_2026-11-06.md)를 읽는다. 로컬 수정이 있으면 먼저 차이를 확인하고 보존한다.
2. 실험동 문 위 타일과 등기구·작업대 밝기를 플레이어 시점에서 확인한다. 승인된 외곽 배치와 프랍 디테일을 기준으로 미세 조정한다.
3. 바닥 안내선·출입구 표식을 제작하고 통행과 주요 시야를 확인한다. 안내선 색·코드·문구는 기존 설계와 대조해 정한다.
4. T01의 배선·재질·조명·안내선 마감 후 C02 경비·모니터링 공동으로 이동한다. 구역마다 제작 → 통행/시각 검수 → 사용자 확인 순서로 진행한다.
5. 다른 공동의 부족 프랍과 VA/VB 층간 계단·참, VL 승강로는 별도 작업이다. 최종 게임 코드와 상호작용은 사용자가 질문하며 직접 구현하는 방침을 유지한다.
