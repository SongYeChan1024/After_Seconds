# After Seconds 11월 12일 작업 마감과 이어하기 V0.01

작성자 송예찬 · 2026-11-12

사용자 요청으로 오늘의 구현 작업을 여기서 마감한다. **B1 실내 재설계·기물 보수와 지상1F 위장 폐공장·지형·반복 무늬 보수**를 함께 저장한다. 다음 작업은 사용자의 전체1F 분위기·표면·지형 검수와 지정 구역 보수다. 기술 검수 통과를 전체 아트의 최종 수용으로 기록하지 않는다.

이 문서는 구현 커밋 전 마감 기록이다. 원격 커밋·블로그 배포 결과는 확인 뒤 아래에 갱신한다. 각 제작 단계 검수 문서의 ‘커밋/push/블로그 미실시’는 해당 단계 당시 상태다.

## 집에서 이어서 시작할 때

1. 로컬 변경을 확인한 뒤 After Seconds와 블로그의 각 저장소에서 `git pull --ff-only`로 최신 main을 받는다. 로컬 변경과 충돌하면 강제 reset/clean하지 않는다.
2. 이 문서 → [이어하기](이어하기_2026-11-12.md) → [최신1F 검수](Review/2026-11-12_1F_Abandoned/Review.md)와 [전후 화면](Review/2026-11-12_1F_Abandoned/review.html)을 읽는다.
3. Unity **6000.4.0f1**로 `Unity/After_Seconds_Build_V0.01`을 연다. 에디터·패키지 자동 업그레이드를 하지 않는다.
4. 최신 씬은 `Assets/Afrer_Seconds/01.Scenes/Stage/Level_1F_Factory.unity`다. 현재 저장된 편집 상태에서 `AE_VA_Walls`를 선택했고 Play·임시 입력 설정은 복구했다.
5. 현재 씬을 먼저 확인하고 요청받은 범위만 수정한다. 이전 제작기·Apply·Import·report를 일괄 재실행하면 후속 수정과 표면 재질이 되돌아갈 수 있다.
