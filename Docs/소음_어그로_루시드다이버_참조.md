# After Seconds 소음·어그로와 루시드 다이버 참조 V0.02

작성자 송예찬 · 2026-11-10

사용자가 제안한 소음·어그로용 오브젝트 풀링을 검토했다. **루시드 다이버의 소음 이벤트·청각 판정·조사 상태 구조를 참고하고, 소음 위치 오브젝트의 수명을 풀에서 관리하는 방식은 적합하다.** 풀은 오브젝트 재사용을 담당하고, 경비가 어떤 자극을 따라갈지는 감지·기억·행동 규칙으로 판단한다. After Seconds의 게임 코드·씬에는 아직 적용하지 않았다.

## 2. After Seconds 적용안

아래는 💡 설계안이다. 세부 반경·강도·감쇠값은 확정하지 않았다.

1. 발소리·투척 충돌·총성 등에서 발생 위치와 게임 시각을 가진 자극을 만든다.
2. 필요할 때 풀에서 소음 기준점·표시 오브젝트를 꺼내 종류·반경·우선순위·남은 수명을 초기화한다.
3. 경비는 실제 청취·차폐와 직접 관측 중인 대상, 최신 유효 관측/신고 정보를 비교해 조사할지 판단한다.
4. 소음이 끝나면 오브젝트를 풀로 돌려보낸다. 경비의 기억·경보 기록은 독립 데이터로 남길 필요가 있는지 규칙에 따라 처리한다.

원본의 `CanInterruptChase`는 추격을 끊고 일정 시간 시야 재획득까지 막을 수 있다. 이를 그대로 가져오면 After Seconds의 **직접 보이는 플레이어 우선** 규칙과 충돌할 수 있다. 일반 물건 충돌음으로 눈앞 플레이어를 잊게 하지 않고, 시야를 잃은 뒤 소리 위치를 조사하게 하는 방향을 우선 검토한다. 특수 유인 도구를 추가한다면 별도 사용자 결정이 필요하다.

루시드 다이버의 평면 거리 기준은 2.5D 공간에 맞춘 코드다. B2의 메자닌·그레이팅·배관과 층별 높이가 있는 After Seconds에는 높이 차이·바닥/벽 차폐·열린 격자의 전파를 따로 설계한다. 원본의 발소리/총성 반경을 그대로 채택하지 않는다. 손전등의 빛 노출은 소음 풀만으로 결정되지 않으며 시각 감지 규칙으로 별도 검토한다.

## 3. 풀 재사용 시 보존할 의미

- **과거 소음 위치와 재사용된 Transform을 구분한다.** 원본 `EnemyNoiseListener`는 앵커 Transform을 따라갈 수 있다. 풀에 반납된 앵커가 다른 곳에서 재사용됐을 때 경비가 새 위치로 따라가면 안 된다. 💡 자극 ID·대여 세대 값과 발생 위치를 기억하고 유효한 같은 자극일 때만 앵커를 참조한다.
- **충돌음은 발생 당시의 위치다.** 물건이나 플레이어가 나중에 이동·교환해도 과거 소음의 위치를 현재 위치로 바꾸지 않는다. 계속 소리를 내는 물건을 추적하는 동작은 새로운 자극 또는 별도 지속 소음으로 표현한다.
- **반납 오브젝트를 초기화한다.** 출처·우선순위·반경·지속시간·참조·표시 상태가 다음 소음에 남지 않도록 한다. 물리 오브젝트 자체도 풀링한다면 속도와 Collider 상태를 별도로 초기화한다.
- **기록 열람 중 수명도 멈춘다.** 갤러리·문서·단말 열람 중 소음 수명, 경비 조사 시간, 교환 예약과 연구원 신고 시간은 같은 게임 시간 기준으로 정지·재개한다. UI 표시나 기록 재생의 시간과 구분한다.
- **경보 전달은 소음 오브젝트 수명과 분리한다.** 무전으로 전달된 관측 정보나 연구원 30초 신고를 소음 마커 반납과 함께 삭제하지 않는다. 층 전환 시에도 전달할 신고 데이터는 보존한다.

## 4. 신고와의 연결

[메인 기획서](AfterSeconds_메인기획서.md)의 사용자 결정대로 연구원은 도주 후 게임 시간 30초 뒤 전체 경보를 울리고, 경비는 추격 중 무전으로 알린다. 경보 위치는 가장 최근의 유효 관측 위치이며 관측 시각·층을 함께 가진다. 전체 경보 활성과 실제 수색 위치를 구분하고, 아직 관측되지 않은 플레이어의 현재 좌표를 조회하지 않는다.

연구원의 30초 시작 사건(도주 시작/안전한 곳 도착)은 확인 중이다. 신고 전 제압에 의한 취소·여러 연구원의 중복 신고·경비 무전 갱신 간격·CCTV 전송 시점은 상세 설계다. 풀 크기·증설 방식과 활성 소음이 많을 때의 처리도 성능 측정 후 정한다.

## 5. 구현 후 검증할 것

소음 A를 들은 경비가 앵커 반납 후 소음 B의 위치를 잘못 따라가지 않는지, 보이는 플레이어보다 보통 소음이 우선하지 않는지, 그레이팅 상하와 벽 차폐가 구별되는지 확인한다. 열람 중 10초를 기다려도 교환·30초 신고·소음 수명이 줄지 않아야 한다. 원격 위치를 공유할 때 오래된 무전이 최신 관측을 덮어쓰지 않고, 출발 층을 해제해도 이미 시작한 신고가 사라지지 않는지 검증한다.
