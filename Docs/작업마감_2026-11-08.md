# After Seconds — B5 돔·안내선 작업 마감 V0.01

작성자 송예찬 · 2026-11-08

사용자가 오늘 작업 종료, After Seconds 커밋·push와 블로그 데일리로그·일일개발일지 작성을 요청했다. 이 마감 문서를 포함한 커밋을 다음 작업 기준으로 사용한다. 아래 단계별 문서의 ‘로컬 저장·커밋/push 미실시’는 각 단계 완료 당시 기록이다. 원격 반영 여부는 `git fetch origin` 후 `HEAD`와 `origin/main`으로 확인한다.

## 현재 기준

- 작업 씬: `Unity/After_Seconds_Build_V0.01/Assets/Afrer_Seconds/01.Scenes/Stage/Level_B5_Circular.unity`.
- 일반 돔12·이동 코어3·복도19의 외형 제작과 공간별 내부 구조·장비 보강을 반영했다. 전체 아트 최종 판정은 사용자 검수 전까지0/34로 유지한다.
- **이동 안내선은 복도에만 배치한다.** 돔과 계단/승강기 내부의 선·방향 화살표·목적지 문자·범례, 실험동 R1/S1/M1 이동 표기는 제거했다. 복도의 목적지 색·방향·문자는 유지한다. 이 결정은 과거 돔 내부 안내선 보존 지침보다 우선한다.
- 장비 작업 표식·적재 경계·문턱 안전 표시는 유지한다. 새로운 구역 명판은 따로 붙이지 않는다.
- B5 전체 조명·색감의 최종 조정은 사용자 외형 검수와 보수 후 진행한다. 실험동의 승인된 배치와 사용자 광원 설정을 무단으로 초기화하지 않는다.
- 편집 모드, 저장된 씬. 플레이어 시작 위치 `(-9.2,-81.36,-10)`, 백그라운드 실행 설정 원복 상태. 새 런타임 C#/Animator 기능은 추가하지 않았다.
- 문 개폐·승강기 층간 운행·장비 화면 갱신·B4 실제 씬 연결은 미구현이다. 계단의 외형/충돌 통행 검수와 층간 게임 연결을 구분한다.

S01은 위치·자세 변화 계측 더미/고정대/추적 장치로, E03은 오염 보호구 회수·밀봉→세정→청결 착용 흐름으로 구체화했다. E02는 직원용 외부 공급 밀봉 식품의 보관·재가열·분배와 피험체용 영양/투약 소모품의 잠금 인계를 구분한다. E01은 중앙6·벽면8 선반과 팔레트·입고 검사·수동 운반 장비를 둔다. VL은 보강 강재 문·문턱 레일·완충대·호출/적재 표시로 화물승강기 역할을 표현한다. C03/C04/S01의 표시등·제어부를 함께 상세화했다.

모델 수량은 단계별 제작 범위다. 교체 전 아트가 비활성 보관되어 있으므로 모든 수치를 합해 현재 활성 수량으로 해석하지 않는다. 제작 원본/스크립트는 `SourceAssets`에, 최종 Unity 모델·재질·텍스처와 `.meta`는 Assets에 함께 보관한다. 이전 전체 생성기/Apply 도구를 최신 씬에 그대로 재실행하지 않는다.

## 검수 결과와 제한

- 공간 구조 보수 후 실제 Controller90/90경로와 Play14구역+복도를 확인했다. 8개 생활실·2개 진료실·관찰/제어/검토실·VA/VB 계단 왕복을 포함한다.
- 장비 보강 후 Controller128/128경로 통과. 기존90경로와 새 장비 앞 접근38경로다. 7구역에서 실제 입력 이동과 새 게임 경고/오류0을 확인했다.
- 장비 단계의 기존38안내경로18,824표본 막힘/바닥 누락0. 이후 시각 안내만 복도 구간으로 축소했다.
- 최종 안내선: 저장 씬 재로드 후89,463정점 검사, 돔 내부0·복도 밖0·기존 안내 재노출0. 19복도 모두 안내 유지, 원본 UV/재질 보존, 문자 중간 절단 방지.
- 안내선 변경 시 기존 Light247개·Collider·기존 Transform3,582개 유지. 기존 Assets5,512개 중 대상 씬만 변경했다. 새 Collider/MonoBehaviour0.
- 안내선 변경 후 Play 이동 검사는 재실시하지 않았다. 형상 검사, 씬 저장/재로드와37개 화면으로 확인했다. Editor 짧은 구간 검수를 최종 빌드 성능 보증으로 해석하지 않는다.

## 다음 작업 순서

1. 다음 PC에서 `git pull --ff-only` 후 이 문서를 먼저 읽는다. 로컬 변경이 있다면 보존하고 차이를 확인한다.
2. [공간 구조 검수 화면](검수/2026-11-08_B5_SpatialRefinement/review.html), [운용 목적·장비 화면](검수/2026-11-08_B5_OperationalDetail/review.html), [최종 안내선 화면](검수/2026-11-08_B5_CorridorOnlyGuidance/review.html)으로 사용자 일괄 외형 검수를 진행한다.
3. 사용자 지적에 맞춰 방의 역할·프랍·간섭을 보수한다. 안내선은 복도에만 두고, 실제 이동/장비 접근과 시야를 함께 확인한다.
4. B5 전체 조명·색감·밝기를 일괄 조정한다. 이후 최종 빌드 성능과 전체 이동을 검수한다.
5. 문/승강기/화면과 B4 연결은 별도 기능 작업이다. 게임 코드는 사용자가 질문하면서 직접 구현하는 방침을 유지한다.
